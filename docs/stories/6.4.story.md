**Key Environmental Interaction Patterns**:
- **Weather-Terrain Priority**: Weather and terrain can coexist, each maintaining independent duration and effects
- **Effect Stacking Order**: Weather multipliers applied first, then terrain bonuses (e.g., Rain +50% Water + Electric Terrain +30% Electric)
- **Status-Environment Interaction**: Misty terrain prevents status, but weather damage bypasses terrain protection
- **Grounding Effects**: Terrain affects only grounded Pokemon, weather affects all Pokemon regardless of grounding
- **Item Interactions**: Heat Rock extends Sunny weather, Terrain Extender extends terrain duration
- **Removal Cascades**: Some abilities/moves can remove multiple environmental effects simultaneously
- **Switch Persistence**: Environmental effects persist when Pokemon switch, but Pokemon-specific interactions reset

**Message Response Pattern** [Source: architecture/tech-stack.md#46-68]:
```lua
ao.send({
    Target = msg.From,
    Action = "EnvironmentalInteraction",
    Data = json.encode({
        environment = environmentalState,
        interactions = {
            weatherEffects = { /* Weather-specific effects */ },
            terrainEffects = { /* Terrain-specific effects */ },
            combinedEffects = { /* Weather+Terrain interactions */ },
            statusInteractions = { /* Status+Environment effects */ }
        },
        calculations = {
            damageMultipliers = { weather = 1.5, terrain = 1.3, combined = 1.95 },
            statusPrevention = { mistyTerrain = true, weatherOverride = false },
            movePrevention = { psychicTerrain = true, weatherBlocking = true }
        }
    }),
    Success = "true",
    ProcessId = ao.id,
    Timestamp = tostring(msg.Timestamp or 0)
})
```

- Wrap operations in pcall only when they might fail (JSON parsing, not simple environmental lookups)
