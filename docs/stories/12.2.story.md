### Core Stellar Tera Mechanics Summary

**Key Differences from Standard Tera:**
1. **One-time STAB boost per type**: Each move type gets Stellar STAB only once per battle (tracked via `stellarTypesBoosted[]`)
2. **Differentiated STAB values**: 1.5x for matching natural types, 1.2x for non-matching types
3. **Neutral type effectiveness**: STELLAR moves always deal 1.0x damage to all types
4. **Defensive type retention**: Stellar Pokemon keep natural types for defense calculations
5. **Terapagos exception**: Always returns STELLAR type and gets unlimited STAB usage

**Critical TypeScript References:**
- Stellar properties and tracking: `src/field/pokemon.ts:258` (stellarTypesBoosted array)
- Terapagos override logic: `src/field/pokemon.ts:2258-2263`
- STAB calculation: `src/field/pokemon.ts:3709-3715`
- Usage tracking: `src/phases/move-effect-phase.ts:351-352`
- Reset mechanics: `src/field/pokemon.ts:5198-5204`


#### Example 2: Terapagos Exception Handling
```lua
-- Terapagos with Stellar Tera (always STELLAR regardless of assignment)
function calculateStellarSTAB(pokemon, moveType)
    if isTerapagos(pokemon.speciesId) then
        -- Bypass usage tracking entirely
        local matchesNaturalType = hasType(pokemon.types, moveType)
        return matchesNaturalType and 1.5 or 1.2
    end
    -- Normal Stellar logic continues...
end

-- Turn 1: Terapagos uses Earth Power (Ground)
local stabMultiplier = 1.2  -- Gets bonus (not natural type)
-- stellarTypesBoosted remains empty for Terapagos

-- Turn 5: Terapagos uses Earth Power again
local stabMultiplier = 1.2  -- Still gets bonus (unlimited)
```

```lua
-- Battle end resets all tracking
```

