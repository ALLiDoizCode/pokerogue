## Story Statement
As a **AI move selection engineer**,
I want **complete damage calculation formulas for KO detection**,
so that **AI accurately predicts which moves can KO opponents**.

## Acceptance Criteria
1. Base damage formula: `((2 * Level / 5 + 2) * Power * (Atk / Def) / 50) + 2`
2. Damage modifiers: STAB (1.5×), type effectiveness (0-8×), critical hits (1.5× or 2×), random variance (0.85-1.0)
3. Stat-based calculation: Attack/Defense for PHYSICAL, SpAtk/SpDef for SPECIAL
4. Critical hit detection: crit-only moves (Storm Throw, Frost Breath), Laser Focus tag, critical hit rates
5. Special move conditions: Sucker Punch (fails if target not attacking), Upper Hand/Thunderclap (priority-based)
6. Move condition checking: applyConditions() equivalent (move-specific failure conditions)
7. Ability interactions: Thick Fat (0.5× Fire/Ice), Filter/Solid Rock (0.75× super effective), Multiscale (0.5× at full HP), Fur Coat (0.5× physical)
8. Weather/terrain modifiers: Rain (1.5× Water, 0.5× Fire), Sun (1.5× Fire, 0.5× Water), Electric Terrain (1.3× Electric), Misty Terrain (0.5× Dragon)
9. KO detection accuracy validation (unit tests: 12+ damage scenarios)
10. Parity tests vs TypeScript damage calculations (15+ scenarios including edge cases)
11. AO compliance maintained (100%)
12. Process size remains under 100KB (expected: 60-70KB with damage formulas)

#### Base Damage Formula
[Source: src/field/pokemon.ts:3666]

```lua
-- TypeScript formula:
-- baseDamage = (levelMultiplier * power * sourceAtk.value) / targetDef.value / 50 + 2
-- where levelMultiplier = (2 * source.level) / 5 + 2

local function calculateBaseDamage(attackerLevel, movePower, attackStat, defenseStat)
    local levelMultiplier = (2 * attackerLevel) / 5 + 2
    local baseDamage = (levelMultiplier * movePower * attackStat) / defenseStat / 50 + 2
    return math.floor(baseDamage)
end
```

local function detectKOMoves(pokemon, opponent, moveQueue, weather, terrain)
    local koMoves = {}
