### Architecture Decision: New Standalone Process
**Rationale for New Process:**
- Voucher economy is distinct from gacha mechanics (currency vs probability systems)
- Voucher system requires balance tracking, generation, redemption, and value calculation logic
- Separation allows focused testing of economic behavior and balance integrity
- Process size management: voucher logic estimated ~18-25KB with embedded type definitions and value mappings
- Future extensibility: voucher economy may expand with advanced features in later stories (currently focused on parity)

**Implementation Strategy:**
- Create new `processes/voucher-economy-engine.lua` process
- Define voucher type constants, tier mappings, and value mappings embedded in process
- Implement handlers: AddVoucher, RedeemVoucher, GetVoucherBalance, GetVoucherInfo
- Maintain stateless design with all voucher balance passed via GameState JSON
- Use deterministic validation for predictable economic behavior
- Voucher values: REGULAR=1, PLUS=5, PREMIUM=10, GOLDEN=25 pulls per voucher

### API Specifications

**Handler: AddVoucher** [Source: Architecture requirements for AO message patterns]
- **Trigger Tag**: `Action = "AddVoucher"`
- **Required Parameters**: `msg.VoucherType` ("REGULAR"|"PLUS"|"PREMIUM"|"GOLDEN"), `msg.Amount` (voucher count)
- **Optional Parameters**: `msg.Source` (achievement or trainer key for unlock tracking)
- **Response**: Updated voucher balance and transaction result
- **Validation**: Voucher type validity, amount positivity
- **Example**:
  ```lua
  -- Request
  {
    Action = "AddVoucher",
    VoucherType = "PREMIUM",
    Amount = "3",
    Source = "CLASSIC_VICTORY"
  }

  -- Response
  {
    Action = "SaveState",
    Success = "true",
    Data = json.encode({
      transactionId = "txn_12345",
      timestamp = 1696800000,
      operation = "ADD",
      voucherType = "PREMIUM",
      amount = 3,
      previousBalance = 2,
      newBalance = 5,
      voucherCounts = {
        [VoucherType.REGULAR] = 10,
        [VoucherType.PLUS] = 5,
        [VoucherType.PREMIUM] = 5,
        [VoucherType.GOLDEN] = 2
      }
    })
  }
  ```

**Handler: RedeemVoucher** [Source: Architecture requirements]
- **Trigger Tag**: `Action = "RedeemVoucher"`
- **Required Parameters**: `msg.VoucherType` ("REGULAR"|"PLUS"|"PREMIUM"|"GOLDEN"), `msg.Amount` (voucher count to redeem)
- **Optional Parameters**: `msg.VoucherCounts` (JSON with current balance)
- **Response**: Updated voucher balance and transaction result

```lua
-- New voucher-economy-engine.lua process
-- Monolithic design with embedded voucher type definitions

local json = require("json")

-- Voucher Type Constants (embedded from voucher.ts)
local VoucherType = {
  REGULAR = 0,
  PLUS = 1,
  PREMIUM = 2,
  GOLDEN = 3
}

-- Voucher Tier Mappings
local VOUCHER_TIER_MAP = {
  [VoucherType.REGULAR] = "COMMON",
  [VoucherType.PLUS] = "GREAT",
  [VoucherType.PREMIUM] = "ULTRA",
  [VoucherType.GOLDEN] = "ROGUE"
}

-- Voucher Name Mappings
local VOUCHER_NAME_MAP = {
  [VoucherType.REGULAR] = "Egg Voucher",
  [VoucherType.PLUS] = "Egg Voucher Plus",
  [VoucherType.PREMIUM] = "Egg Voucher Premium",
  [VoucherType.GOLDEN] = "Egg Voucher Gold"
}

-- Helper functions for voucher economy
local function getVoucherTier(voucherType) ... end
local function getVoucherName(voucherType) ... end
local function validateVoucherBalance(voucherCounts, voucherType, amount) ... end
local function updateVoucherBalance(voucherCounts, voucherType, amount, operation) ... end

-- Handler registration (individual handlers for each action)
Handlers.add("add-voucher",
  Handlers.utils.hasMatchingTag("Action", "AddVoucher"),
  function(msg)
    local voucherType = msg.VoucherType
    local amount = tonumber(msg.Amount)
    local source = msg.Source

    if not voucherType or not amount then
      ao.send({
        Target = msg.From,
        Action = "Error",
        Error = "VoucherType and Amount required"
      })
      return
    end

    -- Validate voucher type
    local voucherTypeValue = VoucherType[voucherType]
    if voucherTypeValue == nil then
      ao.send({
        Target = msg.From,
        Action = "Error",
        Error = "Invalid VoucherType: " .. voucherType
      })
      return
    end

    -- Parse current voucher balance
    local voucherCounts = json.decode(msg.VoucherCounts or "{}")

    -- Update voucher balance
    local previousBalance = voucherCounts[voucherTypeValue] or 0
    voucherCounts[voucherTypeValue] = previousBalance + amount

    -- Generate transaction result
    ao.send({
      Target = msg.From,
      Action = "SaveState",
      Success = "true",
      Data = json.encode({
        transactionId = "txn_" .. tostring(msg.Timestamp),
        timestamp = tonumber(msg.Timestamp),
        operation = "ADD",
        voucherType = voucherType,
        amount = amount,
        previousBalance = previousBalance,
        newBalance = voucherCounts[voucherTypeValue],
        voucherCounts = voucherCounts
      })
    })
  end
)

-- Additional handlers for RedeemVoucher, GetVoucherBalance, GetVoucherInfo
```
