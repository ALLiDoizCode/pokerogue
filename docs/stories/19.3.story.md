### API Specifications

**Process: character-dialogue-engine.lua**

**Handler: GetCharacterDialogue**
- **Input Tags:** TrainerType, DialoguePhase (encounter/victory/defeat), VariantIndex (optional)
- **Output Tags:** Success (true/false), DialogueCount (number of variants), Speaker (trainer name key)
- **Output Data:** JSON dialogue content for requested character and phase
- **Purpose:** Retrieve personality-appropriate dialogue for specific trainer type and situation

**Handler: SelectRandomDialogue**
- **Input Tags:** TrainerType, DialoguePhase, Seed (for deterministic selection)
- **Output Tags:** Success (true/false), VariantIndex (selected variant), Speaker (trainer name key)
- **Output Data:** Randomly selected dialogue text based on seed
- **Purpose:** Deterministically select dialogue variant for personality consistency

**Handler: GetSpeakerName**
- **Input Tags:** TrainerType, VariantIndex (optional for gender/sub-type variants)
- **Output Tags:** Success (true/false), SpeakerKey (i18n key for speaker name)
- **Output Data:** Speaker identification for UI rendering
- **Purpose:** Map TrainerType to speaker name for dialogue attribution

**Handler: InjectDialogueContext**
- **Input Tags:** DialogueText, Data (JSON: dialogueTokens map from encounter)
- **Output Tags:** Success (true/false), TokenCount (number of replacements)
- **Output Data:** Processed dialogue text with context tokens replaced
- **Purpose:** Replace {{tokenName}} placeholders with game-specific values (reuses Story 19.2 logic)

**Handler: ValidatePersonality**
- **Input Tags:** TrainerType, DialoguePhase
- **Output Tags:** Valid (true/false), HasDialogue (true/false), VariantCount (number)
- **Output Data:** Validation result with available dialogue variants
- **Purpose:** Verify trainer type has dialogue defined for requested phase

**Handler: ListAvailablePersonalities**
- **Input Tags:** None
- **Output Tags:** PersonalityCount (total number of trainer types)
- **Output Data:** JSON array of all available TrainerType values with variant counts
- **Purpose:** Enumerate all defined character personalities for debugging/validation

**Handler: Info** (ADP v1.0 Compliance)
- **Input Tags:** Action = "Info"
- **Output Tags:** Success = "true"
- **Output Data:** JSON process metadata
- **Purpose:** Self-documentation for ADP v1.0 compliance

**Random Dialogue Selection:**
[Source: TypeScript uses randSeedInt() for dialogue variant selection]

```lua
-- Deterministic random selection based on seed
local function selectRandomDialogue(trainerType, dialoguePhase, seed)
  local dialogueVariants, err = getCharacterDialogue(trainerType, dialoguePhase)
  if not dialogueVariants then
    return nil, err
  end

  local variantCount = #dialogueVariants
  if variantCount == 0 then
    return nil, "No dialogue variants available"
  end

  -- Use seed for deterministic selection (consistent across restarts)
  local variantIndex = (seed % variantCount) + 1

  return {
    dialogue = dialogueVariants[variantIndex],
    variantIndex = variantIndex,
    variantCount = variantCount
  }
end
```

**Context Injection (Reuse Story 19.2):**
[Source: Story 19.2 implementation]

Story 19.2 already implements `ProcessDialogueTokens` handler:
```lua
-- Character dialogue engine can delegate to dialogue-navigation-engine
-- OR embed the same token replacement logic
local function injectDialogueContext(dialogueText, dialogueTokens)
  -- Reuse Story 19.2 token replacement implementation
  local processedText = dialogueText
  local tokenCount = 0

  for tokenName, tokenValue in pairs(dialogueTokens) do
    local pattern = "{{" .. tokenName .. "}}"
    local replacedText = string.gsub(processedText, pattern, tokenValue)
    if replacedText ~= processedText then
      tokenCount = tokenCount + 1
      processedText = replacedText
    end
  end

  return processedText, tokenCount
end
```

**Personality Validation:**

```lua
local function validatePersonality(trainerType, dialoguePhase)
  local trainerDialogue = TRAINER_DIALOGUE[trainerType]
  if not trainerDialogue then
    return {
      valid = false,
      hasDialogue = false,
      variantCount = 0,
      error = "Unknown trainer type: " .. tostring(trainerType)
    }
  end

  local phaseDialogue = trainerDialogue[dialoguePhase]
  if not phaseDialogue or #phaseDialogue == 0 then
    return {
      valid = false,
      hasDialogue = false,
      variantCount = 0,
      error = "No dialogue for phase: " .. dialoguePhase
    }
  end

  return {
    valid = true,
    hasDialogue = true,
    variantCount = #phaseDialogue
  }
end
```

**Handler Implementation Pattern:**

```lua
-- GetCharacterDialogue handler
Handlers.add("get-character-dialogue",
  Handlers.utils.hasMatchingTag("Action", "GetCharacterDialogue"),
  function(msg)
    local trainerType = tonumber(msg.TrainerType)
    local dialoguePhase = msg.DialoguePhase or "encounter"
    local variantIndex = tonumber(msg.VariantIndex)

    if not trainerType then
      ao.send({
        Target = msg.From,
        Action = "Error",
        Error = "TrainerType required"
      })
      return
    end

    local dialogueVariants, err = getCharacterDialogue(trainerType, dialoguePhase)
    if not dialogueVariants then
      ao.send({
        Target = msg.From,
        Action = "Error",
        Error = err
      })
      return
    end

    -- Get speaker name
    local speakerResult = getSpeakerName(trainerType)

    -- If variantIndex specified, return that variant; otherwise return all
    local responseData
    if variantIndex and variantIndex > 0 and variantIndex <= #dialogueVariants then
      responseData = {
        dialogue = dialogueVariants[variantIndex],
        variantIndex = variantIndex,
        variantCount = #dialogueVariants
      }
    else
      responseData = {
        dialogueVariants = dialogueVariants,
        variantCount = #dialogueVariants
      }
    end

    ao.send({
      Target = msg.From,
      Action = "SaveState",
      Success = "true",
      DialogueCount = tostring(#dialogueVariants),
      Speaker = speakerResult.speakerKey,
      Data = json.encode(responseData)
    })
  end
)
```
