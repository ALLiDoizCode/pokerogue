### TypeScript Reference Implementation
**Entry Hazard Implementation Points** [Source: typescript-reference/src/data/arena-tag.ts]:

**SpikesTag Class**:
- Extends DamagingTrapTag with maxLayers: 3
- Damage calculation: 1/8, 1/6, 1/4 max HP for layers 1, 2, 3 respectively
- Only affects grounded Pokemon (groundedOnly: true)
- Blocked by Magic Guard ability

**StealthRockTag Class**:
- Extends DamagingTrapTag with maxLayers: 1
- Affects all Pokemon including Flying types (groundedOnly: false)
- Damage calculation: 1/8 max HP × type effectiveness multiplier
- Type effectiveness applied: Rock vs entering Pokemon's types

**ToxicSpikesTag Class**:
- Extends EntryHazardTag with maxLayers: 2
- Layer 1: Regular poison, Layer 2: Badly poisoned
- Grounded Pokemon only, neutralized by Poison-type Pokemon entering
- No direct damage, applies status conditions instead

**StickyWebTag Class**:
- Extends EntryHazardTag with maxLayers: 1
- Reduces Speed stat by one stage on entry
- Only affects grounded Pokemon
- No damage calculation, stat modification only

**Entry Hazard Base Logic**:
- All hazards are side-specific (ArenaTagSide.PLAYER or ArenaTagSide.ENEMY)
- Hazards persist until removed by moves (Rapid Spin, Defog) or abilities (Magic Bounce)
- Layer stacking increases effectiveness up to maxLayers limit
- Magic Guard blocks damage from Spikes and Stealth Rock

```lua
EntryHazardState = {

    immuneReason = "string" -- Reason for immunity if applicable
}
```

### API Specifications
**Entry Hazard Process Message Protocol** [Source: architecture/tech-stack.md#process-communication-protocol]:

**Incoming Message Structure**:
```lua
-- Place hazard
msg = {
    Action = "PlaceEntryHazard",
    HazardType = "SPIKES|STEALTH_ROCK|TOXIC_SPIKES|STICKY_WEB",
    Side = "PLAYER|ENEMY",
    SourceId = "123", -- Pokemon ID (as string)
    SourceMove = "SPIKES", -- Move that created hazard
    BattleId = "battle_123",
    Timestamp = "1234567890"
}

-- Activate hazards on Pokemon entry
msg = {
    Action = "ActivateEntryHazards",
    PokemonData = "json_encoded_pokemon_data",
    Side = "PLAYER|ENEMY", -- Side entering Pokemon is on
    BattleId = "battle_123",
    Timestamp = "1234567890"
}

-- Remove hazards
msg = {
    Action = "RemoveEntryHazards",
    RemovalType = "RAPID_SPIN|DEFOG|MAGIC_BOUNCE",
    Side = "PLAYER|ENEMY|BOTH", -- Which side's hazards to remove
    BattleId = "battle_123",
    Timestamp = "1234567890"
}
```

**Outgoing Response Structure**:
```lua
ao.send({
    Target = msg.From,
    Action = "SaveState",
    Data = json.encode({
        hazardState = hazardStateData,
        activationResult = {
            activated = true,
            damage = 25, -- Damage dealt
            statusEffect = "POISON", -- Status applied if any
            statChanges = { speed = -1 }, -- Stat modifications
            immuneReason = "" -- Empty if not immune
        }
    }),
    Success = "true",
    ProcessId = ao.id,
    Timestamp = tostring(msg.Timestamp or 0)
})
```

### Technical Constraints  
**AO Runtime Constraints** [Source: architecture/tech-stack.md]:
- 5-second execution timeout per handler
- 500KB maximum file size  
- No math.random() - use deterministic RNG passed in messages
- No os.time() - use msg.Timestamp for time tracking
- Monolithic design - all code in single file

**Entry Hazard Specific Constraints**:
- Damage calculations must use exact fractions: 1/8, 1/6, 1/4 for Spikes layers
- Type effectiveness calculations must match TypeScript type chart exactly
- Layer limits strictly enforced: Spikes (3), Toxic Spikes (2), Stealth Rock (1), Sticky Web (1)
- Status effects must follow exact poison progression patterns
- Magic Guard immunity must be checked before any damage application

**Coding Standards** [Source: architecture/coding-standards.md]:
- Never use math.random() - use AO crypto module for deterministic RNG
- Match TypeScript Math.floor/Math.ceil exactly for damage calculations  
- Include success boolean in all responses
- Reference embedded database tables for type effectiveness data
- Maintain deterministic behavior for replay capability
- Ensure exact damage fractions: 12.5% (1/8), 16.67% (1/6), 25% (1/4)
