### Data Models

**Player Model Progression Data** [Source: architecture/data-models.md#Player Model]:
- `progression`: table - Game progression state including wave advancement and feature unlocks
- `party`: table - Current Pokemon party with individual progression tracking
- `pcStorage`: table - PC Pokemon storage system with progression-related data
- `inventory`: table - Items including progression-affecting items (vitamins, berries, experience enhancers)
- `pokedex`: table - Species seen/caught tracking for completion achievements
- `gameStats`: table - Battle wins, losses, playtime, progression statistics for achievement tracking

**Pokemon Model Progression Context** [Source: architecture/data-models.md#Pokemon Model]:
- `level`: number - Current Pokemon level (1-100 range) for progression calculations
- `exp`: number - Total experience points for level progression
- `stats`: table - Current battle stats [HP, ATK, DEF, SPATK, SPDEF, SPEED] affected by level
- `friendship`: number - Current friendship value (0-255 range) affecting progression bonuses
- `battleData`: table - Temporary battle-specific progression data

**Battle Model Progression Impact** [Source: architecture/data-models.md#Battle Model]:
- `battleSeed`: string - Deterministic seed for progression-related RNG operations
- `turnCommands`: table - Actions affecting player progression (victory conditions, experience gain)
- `conditions`: table - Field conditions that may affect progression calculations

### API Specifications

**Message Protocol for Player Progression** [Source: architecture/tech-stack.md#process-communication-protocol]:
```lua
-- Incoming Message Structure for Player Progression Operations
msg = {
    Action = "ProcessLogic",
    Data = {
        operation = "updatePlayerLevel", -- or "checkUnlockConditions", "updateAchievementProgress", "getPlayerStatistics"
        gameState = {
            player = { 
                progression = {
                    level = 25,
                    experience = 15000,
                    wavesCleared = 10,
                    achievements = {},
                    statistics = {},
                    unlocks = {}
                },
                party = {}, -- Pokemon party for progression calculations
                inventory = {}, -- Items affecting progression
                gameStats = {} -- Statistics for achievement tracking
            }
        },
        parameters = {
            progressionAction = "levelUp", -- levelUp, achievement, unlock, reward
            actionContext = "battleVictory", -- battleVictory, capture, milestone, manual
            progressionData = {}, -- Specific progression data for the action
            multiCharacter = false -- For multi-character progression tracking
        }
    }
}

-- Response Message Structure
ao.send({
    Target = msg.From,
    Action = "SaveState", -- or "Error" for invalid operations
    Success = "true",
    Operation = "updatePlayerLevel", 
    Data = {
        progressionChange = {
            levelGained = 1,
            newLevel = 26,
            experienceGained = 1000,
            totalExperience = 16000
        },
        unlocks = {
            newFeatures = {"advanced_moves", "breeding_center"},
            newAchievements = {"level_25_trainer"}
        },
        rewards = {
            items = ["rare_candy", "master_ball"],
            experience = 500
        },
        statistics = {
            totalBattles = 150,
            totalVictories = 120,
            playtimeHours = 25
        }
    },
    GameState = json.encode(updated_gamestate)
})
```
