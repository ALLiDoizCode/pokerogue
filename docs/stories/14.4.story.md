**Epic:** Epic 14 - Egg System & Breeding Mechanics  
**Status:** Done

## Story Statement
As a **hatching system engineer**,  
I want **egg hatching and incubation systems migrated to stateless AO process**,  
so that **hatching mechanics and timing maintain identical functionality to TypeScript**.

## Acceptance Criteria
1. Egg step counter algorithms maintain identical progression tracking and completion detection
2. Hatching probability calculations maintain identical success rate determination and timing
3. Incubation effect modifiers maintain identical acceleration and enhancement behavior
4. Hatched Pokemon generation maintains identical stat calculation and trait assignment
5. Hatching animation and presentation maintains identical timing and visual behavior
6. Egg inventory management maintains identical storage and organization functionality
7. Mass hatching operations maintain identical batch processing and completion handling
8. Comprehensive testing validates 100% hatching system mechanical and timing parity

- Critical lessons from previous stories:
  - Monolithic design with all dependencies embedded (no require() statements except json)
  - Direct error handling without excessive pcall usage (only for genuinely unpredictable operations)
  - Proper AO message coordination between processes using ao.send() with structured Target, Action, Data
  - Process size targets: 35-45KB for complex logic processes (well within 500KB limit)
  - ADP v1.0 compliance required with Info handler for self-documentation
  - Tag-based message parameters for simple values, Data field for complex structures
  - Avoid module-level returns - use message passing exclusively
  - All tag values MUST be strings: tostring(number), "true"/"false" for booleans

  - `breeding-compatibility-engine.lua` - Breeding pair validation for egg generation

  - `pokemon-instance-manager.lua` - Individual Pokemon creation after hatching
  - `coordinator-process.lua` - Central orchestration for multi-process operations

#### Process Message Interface (derived from tech-stack.md patterns)

##### Step Progression Messages
```lua
-- Incoming: Progress egg steps
msg = {
    Action = "ProgressSteps",
    EggId = "egg_id",
    Steps = "100",  -- Number of steps to add
    From = "sender_address"
}

-- Outgoing: Step progress confirmation
ao.send({
    Target = msg.From,
    Action = "StepProgressUpdate",
    EggId = msg.EggId,
    CurrentSteps = tostring(currentSteps),
    RequiredSteps = tostring(requiredSteps),
    IsReady = tostring(isReadyToHatch),
    Timestamp = tostring(msg.Timestamp)
})
```

##### Hatching Operations
```lua
-- Incoming: Hatch single egg
msg = {
    Action = "HatchEgg",
    EggId = "egg_id",
    From = "player_address"
}

-- Incoming: Mass hatch operation
msg = {
    Action = "MassHatch",
    EggIds = json.encode({"egg1", "egg2", "egg3"}),  -- Array in Data field
    From = "player_address"
}

-- Outgoing: Hatched Pokemon data
ao.send({
    Target = msg.From,
    Action = "HatchComplete",
    EggId = msg.EggId,
    Data = json.encode({
        pokemon = pokemonData,
        inheritedMoves = moveList,
        parentTraits = traitData
    }),
    ProcessId = ao.id,
    Timestamp = tostring(msg.Timestamp)
})

-- Outgoing: Mass hatch results
ao.send({
    Target = msg.From,
    Action = "MassHatchComplete",
    Data = json.encode({
        results = hatchResults,  -- Array of hatched Pokemon
        failed = failedEggs      -- Any eggs that couldn't hatch
    }),
    Timestamp = tostring(msg.Timestamp)
})
```

### Coordinator Integration Sequences
#### Egg Hatching Workflow
```lua
-- Step 1: Client initiates hatching
ClientRequest -> coordinator-process {
    Action = "HatchEgg",
    EggId = "egg_123",
    PlayerId = "player_456"
}

-- Step 2: Coordinator fetches egg data
coordinator-process -> egg-hatching-engine {
    Action = "GetEggDetails",
    EggId = "egg_123"
}

-- Step 3: Validate egg is ready
egg-hatching-engine -> coordinator-process {
    Action = "EggDetailsResponse",
    Data = json.encode({
        eggId = "egg_123",
        species = "pikachu",
        isReady = true,
        parentData = {...}
    })
}

-- Step 4: Get species data
coordinator-process -> pokemon-species-db {
    Action = "GetSpecies",
    SpeciesId = "pikachu"
}

-- Step 5: Get inherited traits (for bred eggs)
coordinator-process -> genetic-inheritance-engine {
    Action = "CalculateInheritance",
    Data = json.encode({
        parent1 = parentData.parent1,
        parent2 = parentData.parent2,
        species = "pikachu"
    })
}

-- Step 6: Get inherited moves
coordinator-process -> egg-move-learning-engine {
    Action = "GetEggMoves",
    Data = json.encode({
        species = "pikachu",
        parent1Moves = {...},
        parent2Moves = {...}
    })
}

-- Step 7: Generate Pokemon instance
coordinator-process -> pokemon-instance-manager {
    Action = "CreatePokemon",
    Data = json.encode({
        species = speciesData,
        ivs = inheritedTraits.ivs,
        nature = inheritedTraits.nature,
        ability = inheritedTraits.ability,
        moves = eggMoves,
        level = 1
    })
}

-- Step 8: Update egg status
coordinator-process -> egg-hatching-engine {
    Action = "MarkHatched",
    EggId = "egg_123",
    PokemonId = "new_pokemon_789"
}

-- Step 9: Return to client
coordinator-process -> Client {
    Action = "HatchComplete",
    Data = json.encode({
        success = true,
        pokemon = pokemonInstance,
        eggId = "egg_123"
    })
}
```
