- Trigger logic: Executes MoveEffectPhase with DELAYED_ATTACK mode

**WishTag Implementation** (lines 144-174):
- Position-based healing mechanic
- `healHp: number` - Pre-calculated healing amount (50% of user's max HP)
- `pokemonName: string` - Source Pokemon name for messaging
- Trigger logic: Executes PokemonHealPhase at target position
- Validation: Target must exist and not be fainted

**BattlerIndex System** [Source: typescript-reference/src/enums/battler-index.ts]:
```typescript
enum BattlerIndex {
  ATTACKER = -1,  // Special value for self-targeting
  PLAYER,         // Player's Pokemon (position 0)
  PLAYER_2,       // Player's second Pokemon in double battles (position 1)
  ENEMY,          // Enemy Pokemon (position 2)
  ENEMY_2         // Enemy second Pokemon in double battles (position 3)
}
```

**PositionalTagManager Implementation** [Source: typescript-reference/src/data/positional-tags/positional-tag-manager.ts]:
- `tags: PositionalTag[]` - Array of all active positional effects
- `canAddTag()` - Prevents duplicate tags on same position
- `activateAllTags()` - Turn processing with creation order priority
- Turn decrement: `--tag.turnCount` with activation on 0
- Activation order: By creation time, not current speed order

**Position-Dependent Move Effects**:
- Multi-target moves in double battles use position arrays
- Range calculations based on BattlerIndex proximity
- Damage distribution considers position-specific modifiers
- Targeting validation ensures position availability

### Data Models
**Positional Mechanic State Model** [Source: architecture/data-models.md#battle-model]:
```lua
PositionalMechanicState = {
    tagType = "string", -- DELAYED_ATTACK, WISH
    targetIndex = "number", -- BattlerIndex (0=PLAYER, 1=PLAYER_2, 2=ENEMY, 3=ENEMY_2)
    turnsRemaining = "number", -- Turn count until activation
    sourceId = "number", -- Pokemon ID that created the effect (for delayed attacks)
    sourceMove = "string", -- Move that created the effect
    parameters = "table", -- Tag-specific parameters (healHp for Wish, damage for DelayedAttack)
    pokemonName = "string" -- Source Pokemon name (for Wish messaging)
}

PositionalMechanicResult = {
    applied = "boolean", -- Whether effect was successfully applied
    targetPosition = "number", -- BattlerIndex where effect is targeted
    activationTurn = "number", -- Turn when effect will trigger
    effectType = "string", -- Type of positional effect applied
    canStack = "boolean", -- Whether multiple effects can target same position
    validTarget = "boolean" -- Whether target position currently has valid Pokemon
}
```

### API Specifications
**Positional Mechanic Process Message Protocol** [Source: architecture/tech-stack.md#process-communication-protocol]:

**Incoming Message Structure**:
```lua
-- Apply positional effect
msg = {
    Action = "ApplyPositionalEffect",
    TagType = "DELAYED_ATTACK|WISH",
    TargetIndex = "0", -- BattlerIndex (0-3)
    TurnsRemaining = "2", -- Turn delay
    SourceId = "123", -- Pokemon ID (as string)
    SourceMove = "FUTURE_SIGHT", -- Move name
    Parameters = json.encode({...}), -- Tag-specific data
    BattleId = "battle_123",
    Timestamp = "1234567890"
}

-- Check positional targeting
msg = {
    Action = "CheckPositionalTargeting",
    SourceIndex = "0", -- Attacker position
    TargetIndices = "2,3", -- Target positions (comma-separated)
    MoveId = "EARTHQUAKE", -- Move being used
    RangeType = "ADJACENT|ALL|OPPOSITE", -- Targeting pattern
    BattleId = "battle_123",
    Timestamp = "1234567890"
}

-- Process positional turn effects
msg = {
    Action = "ProcessPositionalTurnEffects",
    ActiveTags = json.encode({...}), -- All active positional tags
    TurnPhase = "START|END", -- When processing occurs
    BattleId = "battle_123",
    Timestamp = "1234567890"
}

-- Update battlefield positions
msg = {
    Action = "UpdateBattlefieldPositions",
    PositionData = json.encode({...}), -- Current Pokemon at each position
    SwitchEvents = json.encode({...}), -- Position changes this turn
    BattleId = "battle_123",
    Timestamp = "1234567890"
}
```

**Outgoing Response Structure**:
```lua
ao.send({
    Target = msg.From,
    Action = "SaveState",
    Data = json.encode({
        positionalMechanicState = positionalMechanicStateData,
        mechanicResult = {
            applied = true,
            targetPosition = 2, -- BattlerIndex
            activationTurn = 5, -- Turn when effect triggers
            effectType = "DELAYED_ATTACK",
            canStack = false, -- Cannot stack same tag type on position
            validTarget = true -- Position has valid Pokemon
        },
        activeTags = {...}, -- All currently active positional tags
        positionStates = {...} -- Current Pokemon at each battlefield position
    }),
    Success = "true",
    ProcessId = ao.id,
    Timestamp = tostring(msg.Timestamp or 0)
})
```
