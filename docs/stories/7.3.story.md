### TypeScript Reference Implementation
**Complex Field Condition Implementation Points** [Source: typescript-reference/src/data/arena-tag.ts]:

**Room Arena Tags** (lines 1158-1171):
- Abstract base class for room effects (Trick Room, Wonder Room, Magic Room)
- Immediate removal upon overlap to prevent stacking
- Side-independent effects affecting entire field
- Override behavior: newer room replaces older room

**Trick Room Implementation** (lines 1174-1216):
- Reverses speed-based turn order for all Pokemon
- Duration: 5 turns by default
- Effect: `speedReversed.value = !speedReversed.value`
- Messaging: Queue add/remove messages for battle visualization

**Gravity Implementation** (lines 1218-1269):
- Grounds all Pokemon including Flying-types and Levitate users
- Duration: 5 turns by default
- Effects: Removes FLOATING, TELEKINESIS, and interrupts FLYING status
- Complex interaction with multiple battler tags

**Imprison Implementation** (lines 1092-1155):
- Applies to all opposing Pokemon that switch in while source is active
- Adds BattlerTagType.IMPRISON to affected Pokemon
- Complex lifecycle: lapse checks if source Pokemon still active
- Removal cascade: removes all related battler tags on arena tag removal

**Multi-Turn Future Attack Tags** (lines 1400-1500):
- Future Sight and Doom Desire with delayed damage execution
- Complex timing: activates after specific turn count
- State persistence: maintains attack parameters across turns
- Damage calculation: uses original attacker's stats

### Data Models
**Field Condition State Model** [Source: architecture/data-models.md#battle-model]:
```lua
FieldConditionState = {
    conditionType = "string", -- TRICK_ROOM, WONDER_ROOM, MAGIC_ROOM, GRAVITY, IMPRISON, FUTURE_SIGHT, DOOM_DESIRE
    turnsRemaining = "number", -- Turn count (typically 5, or delayed execution count)
    sourceId = "number", -- Pokemon ID that created the condition
    sourceMove = "string", -- Move that created the condition
    side = "string", -- PLAYER, ENEMY, or BOTH for field-wide effects
    priority = "number", -- Resolution order priority (higher = resolved first)
    parameters = "table", -- Condition-specific parameters (future attack damage, etc.)
    affectedPokemon = "table" -- List of Pokemon affected by condition (for Imprison)
}

FieldConditionResult = {
    applied = "boolean", -- Whether condition was successfully applied
    replaced = "boolean", -- Whether previous condition was replaced
    priorityAdjustment = "number", -- Speed priority modification (Trick Room)
    groundedPokemon = "table", -- Pokemon affected by grounding (Gravity)
    imprisonedMoves = "table", -- Moves disabled by Imprison
    futureAttack = "table" -- Future attack parameters if applicable
}
```

### API Specifications
**Field Condition Process Message Protocol** [Source: architecture/tech-stack.md#process-communication-protocol]:

**Incoming Message Structure**:
```lua
-- Apply field condition
msg = {
    Action = "ApplyFieldCondition",
    ConditionType = "TRICK_ROOM|WONDER_ROOM|MAGIC_ROOM|GRAVITY|IMPRISON",
    SourceId = "123", -- Pokemon ID (as string)
    SourceMove = "TRICK_ROOM", -- Move that created condition
    Side = "BOTH", -- PLAYER, ENEMY, or BOTH
    Duration = "5", -- Turn duration
    Parameters = json.encode({...}), -- Condition-specific parameters
    BattleId = "battle_123",
    Timestamp = "1234567890"
}

-- Apply future attack
msg = {
    Action = "ApplyFutureAttack",
    AttackType = "FUTURE_SIGHT|DOOM_DESIRE",
    SourceId = "123", -- Original attacker Pokemon ID
    TargetId = "456", -- Target Pokemon ID
    Damage = "150", -- Pre-calculated damage amount
    DelayTurns = "2", -- Turns until activation
    AttackData = json.encode({...}), -- Attack parameters
    BattleId = "battle_123",
    Timestamp = "1234567890"
}

-- Check field condition effects
msg = {
    Action = "CheckFieldConditionEffects",
    ConditionTypes = "TRICK_ROOM,GRAVITY", -- Conditions to check
    CheckType = "SPEED_PRIORITY|GROUNDING|MOVE_RESTRICTION",
    PokemonId = "123", -- Pokemon being checked
    MoveId = "TACKLE", -- Move being used (for Imprison check)
    BattleId = "battle_123",
    Timestamp = "1234567890"
}

-- Process field condition interactions
msg = {
    Action = "ProcessFieldConditionInteractions",
    ActiveConditions = json.encode({...}), -- All active field conditions
    NewCondition = json.encode({...}), -- Condition being added
    InteractionType = "OVERLAP|CASCADE|PRIORITY",
    BattleId = "battle_123",
    Timestamp = "1234567890"
}
```

**Outgoing Response Structure**:
```lua
ao.send({
    Target = msg.From,
    Action = "SaveState",
    Data = json.encode({
        fieldConditionState = fieldConditionStateData,
        conditionResult = {
            applied = true,
            replaced = false, -- Whether previous condition was replaced
            priorityAdjustment = -1, -- Speed priority modification
            groundedPokemon = {"123", "456"}, -- Pokemon affected by grounding
            imprisonedMoves = {"TACKLE", "QUICK_ATTACK"}, -- Disabled moves
            futureAttackScheduled = true -- Future attack queued
        },
        activeConditions = {...} -- All currently active field conditions
    }),
    Success = "true",
    ProcessId = ao.id,
    Timestamp = tostring(msg.Timestamp or 0)
})
```
