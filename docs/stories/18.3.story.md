1. **CLASSIC** (GameModes.CLASSIC = 0)

   - Final wave: 200
   - Starting level: 5 (default)
   - Starting biome: BiomeId.TOWN
   - Shop: Enabled
   - Fixed battles: classicFixedBattles

2. **ENDLESS** (GameModes.ENDLESS = 1)
   - Endless mode: isEndless = true, hasShortBiomes = true, hasRandomBosses = true
   - Final wave: Every 250 waves (minor boss)
   - Endless bosses: Every 50 waves (paradox pokemon)
   - Major bosses: Every 1000 waves (Eternamax Eternatus)
   - Starting level: 5 (default)
   - Shop: Enabled
   - Enemy modifier chance: 12 (non-boss), 4 (boss)

3. **SPLICED_ENDLESS** (GameModes.SPLICED_ENDLESS = 2)
   - Spliced endless mode: isEndless = true, hasShortBiomes = true, hasRandomBosses = true, isSplicedOnly = true
   - Same wave structure as ENDLESS
   - Restriction: Spliced Pokemon only

4. **DAILY** (GameModes.DAILY = 3)
   - Daily run mode: isDaily = true, hasTrainers = true, hasNoShop = true
   - Final wave: 50
   - Starting level: 20
   - Starting biome: Random (getDailyStartingBiome)
   - Shop: Disabled (hasNoShop = true)
   - Trainer waves: 5, 15, 20, 25, 30, 35, 40, 45
   - Trainer bosses: Every 10 waves (10-40)
   - Wave difficulty: waveIndex + 30 + floor(waveIndex / 5)
   - Clear score bonus: 2500
   - Final boss: Event seed boss or random legendary/mythical

5. **CHALLENGE** (GameModes.CHALLENGE = 4)
   - Challenge mode: isClassic = true, hasTrainers = true, isChallenge = true, hasMysteryEncounters = true
   - Same structure as CLASSIC with active challenges

   - Clear score bonus: 5000

**Wave Difficulty Calculation:**
```typescript
getWaveForDifficulty(waveIndex, ignoreCurveChanges = false): number {
    switch (this.modeId) {
        case GameModes.DAILY:
            // Daily: waveIndex + 30 + floor(waveIndex / 5)
            return waveIndex + 30 + (!ignoreCurveChanges ? Math.floor(waveIndex / 5) : 0);
        default:
            // All other modes: no modification
            return waveIndex;
    }
}
```

**Trainer Wave Detection:**
```typescript
isWaveTrainer(waveIndex, arena): boolean {
    if (this.isDaily) {
        // Daily: 5, 15, 20, 25, 30, 35, 40, 45
        return waveIndex % 10 === 5 || (!(waveIndex % 10) && waveIndex > 10 && !this.isWaveFinal(waveIndex));
    }
    // Classic/Challenge: Gym leaders on wave 20/50/80/... (or 30/60/90/... with offset)
    if (waveIndex % 30 === (globalScene.offsetGym ? 0 : 20) && !this.isWaveFinal(waveIndex)) {
        return true;
    }
    // Generic trainers: Probabilistic based on arena.getTrainerChance()
    // Cannot spawn within 2 waves of fixed trainer battle
    if (waveIndex % 10 !== 1 && waveIndex % 10) {
        const trainerChance = arena.getTrainerChance();
        // Complex logic checking nearby waves for conflicts...
        return allowTrainerBattle && trainerChance && !randSeedInt(trainerChance);
    }
    return false;
}
```

**Boss Wave Detection:**
```typescript
isBoss(waveIndex): boolean {
    return waveIndex % 10 === 0;  // All modes: every 10 waves
}

isEndlessBoss(waveIndex): boolean {
    // Endless: Every 50 waves (paradox pokemon)
    return waveIndex % 50 === 0 && (this.modeId === ENDLESS || this.modeId === SPLICED_ENDLESS);
}

isEndlessMinorBoss(waveIndex): boolean {
    // Endless: Every 250 waves (Eternatus)
    return waveIndex % 250 === 0 && (this.modeId === ENDLESS || this.modeId === SPLICED_ENDLESS);
}

isEndlessMajorBoss(waveIndex): boolean {
    // Endless: Every 1000 waves (Eternamax Eternatus)
    return waveIndex % 1000 === 0 && (this.modeId === ENDLESS || this.modeId === SPLICED_ENDLESS);
}

isBattleClassicFinalBoss(waveIndex): boolean {
    return (this.modeId === CLASSIC || this.modeId === CHALLENGE) && this.isWaveFinal(waveIndex);
}

isWaveFinal(waveIndex, modeId = this.modeId): boolean {
    switch (modeId) {
        case CLASSIC:
        case CHALLENGE:
            return waveIndex === 200;
        case ENDLESS:
        case SPLICED_ENDLESS:
            return !(waveIndex % 250);  // Every 250 waves
        case DAILY:
            return waveIndex === 50;
    }
}
```

**Trainer Boss Detection:**
```typescript
isTrainerBoss(waveIndex, biomeType, offsetGym): boolean {
    switch (this.modeId) {
        case DAILY:
            // Daily: Waves 20, 30, 40 (not 10 or 50)
            return waveIndex > 10 && waveIndex < 50 && !(waveIndex % 10);
        default:
            // Classic/Challenge: Gym leaders
            return waveIndex % 30 === (offsetGym ? 0 : 20) &&
                   (biomeType !== BiomeId.END || this.isClassic || this.isWaveFinal(waveIndex));
    }
}
```

**Fixed Battle System:**
```typescript
isFixedBattle(waveIndex): boolean {
    const dummyConfig = new FixedBattleConfig();
    return this.battleConfig.hasOwnProperty(waveIndex) ||
           applyChallenges(ChallengeType.FIXED_BATTLES, waveIndex, dummyConfig);
}

getFixedBattle(waveIndex): FixedBattleConfig {
    const challengeConfig = new FixedBattleConfig();
    if (applyChallenges(ChallengeType.FIXED_BATTLES, waveIndex, challengeConfig)) {
        return challengeConfig;
    }
    return this.battleConfig[waveIndex];
}
```

setChallengeValue(challenge, value) {
    if (!this.isChallenge) {
        this.isChallenge = true;
        this.challenges = allChallenges.map(c => copyChallenge(c));

    this.challenges.filter(chal => chal.id === challenge).map(chal => (chal.value = value));

isFullFreshStartChallenge(): boolean {

**Override Species (Daily Final Boss):**
```typescript
getOverrideSpecies(waveIndex): PokemonSpecies | null {
    if (this.isDaily && this.isWaveFinal(waveIndex)) {
        const eventBoss = getDailyEventSeedBoss(globalScene.seed);
        if (eventBoss) {
            return getPokemonSpecies(eventBoss.speciesId);
        }
        // Fallback: Random legendary/mythical with baseTotal >= 600
        const allFinalBossSpecies = allSpecies.filter(s =>
            (s.subLegendary || s.legendary || s.mythical) &&
            s.baseTotal >= 600 &&
            s.speciesId !== SpeciesId.ETERNATUS &&
            s.speciesId !== SpeciesId.ARCEUS
        );
        return randSeedItem(allFinalBossSpecies);
    }
    return null;
}

### API Specifications

[Source: AO Process handler pattern from tech-stack.md, game-mode.ts analysis]

**Handler Specifications:**

1. **CreateGameMode** - Initialize game mode instance
   - Input: ModeId (enum 0-4)
   - Validation: ModeId in range [0-4]
   - Output: GameMode instance with mode-specific configuration
   - Factory pattern: Creates instance with predefined config based on modeId

2. **GetGameModeInfo** - Query game mode metadata
   - Input: ModeId (optional, omit for all)
   - Output: Game mode configuration and properties
   - Metadata: modeId, isClassic, isEndless, isDaily, hasTrainers, hasNoShop, hasMysteryEncounters, etc.

3. **SetChallengeValue** - Enable challenges and set values
   - Input: ModeId, ChallengeId, Value
   - Validation: ModeId valid, ChallengeId valid, Value within bounds
   - Output: Updated GameMode with isChallenge = true and challenge array
   - Side effect: Initializes challenges array if not already present

4. **IsWaveTrainer** - Determine if wave has trainer battle
   - Input: ModeId, WaveIndex, ArenaData (for trainer chance probability)
   - Complex logic: Daily mode pattern (5, 15, 20, ...), gym leaders, generic trainers
   - Output: Boolean trainer status
   - Uses: Seeded RNG for probabilistic trainer spawns (arena.getTrainerChance)

5. **IsWaveFinal** - Check if wave is final for mode
   - Input: ModeId, WaveIndex
   - Output: Boolean final wave status
   - Mode-specific: Classic/Challenge = 200, Endless = every 250, Daily = 50

6. **GetStartingParameters** - Get starting level, money, biome
   - Input: ModeId
   - Output: StartingLevel, StartingMoney, StartingBiome
   - Mode-specific: Daily level = 20, biome = random; Others: level = 5, biome = TOWN

7. **GetWaveClassification** - Classify wave type (boss, trainer boss, etc.)
   - Input: ModeId, WaveIndex, BiomeType, OffsetGym
   - Output: isBoss, isTrainerBoss, isEndlessBoss, isEndlessMinorBoss, isEndlessMajorBoss, isFinalBoss
   - Complex logic: Multiple boss type checks for Endless modes

8. **GetFixedBattleConfig** - Retrieve fixed battle configuration
   - Input: ModeId, WaveIndex, Challenges (active challenges)
   - Validation: Wave has fixed battle (battleConfig or challenge-based)
   - Output: FixedBattleConfig instance with trainer/battle specifications
   - Challenge integration: applyChallenges(ChallengeType.FIXED_BATTLES)

9. **GetModeRewards** - Calculate mode-specific rewards
   - Input: ModeId, IsBoss (boolean)
   - Output: ClearScoreBonus, EnemyModifierChance
   - Mode-specific: Classic/Challenge = 5000 clear bonus, Endless = 0

10. **GetOverrideSpecies** - Get daily run final boss override
    - Input: ModeId, WaveIndex, Seed
    - Validation: isDaily && isWaveFinal
    - Output: PokemonSpecies (event boss or random legendary/mythical)
    - Complex logic: Event seed boss lookup or filtered legendary selection

11. **GetWaveForDifficulty** - Calculate effective wave difficulty
    - Input: ModeId, WaveIndex, IgnoreCurveChanges (boolean)
    - Output: Effective difficulty value
    - Mode-specific: Daily adds 30 + floor(waveIndex / 5)

12. **GetShopStatus** - Check if shop is available
    - Input: ModeId, Challenges (active challenges)
    - Output: Boolean shop availability
    - Challenge integration: applyChallenges(ChallengeType.SHOP) can override

13. **GetMysteryEncounterWaves** - Get ME legal wave range
    - Input: ModeId
    - Output: [minWave, maxWave]
    - Mode-specific: Classic/Challenge = [10, 180], Others = [0, 0]

14. **Info** - ADP v1.0 self-documentation handler
    - Input: None (Action = "Info")
    - Output: Process metadata with capabilities and message schemas

local function isWaveTrainer(self, waveIndex, arenaData)

        -- Check for event seed boss
        local eventBoss = getDailyEventSeedBoss(seed)
        if eventBoss then
            return {speciesId = eventBoss.speciesId}

   -- ✅ CORRECT: Embedded game mode factory functions

       return createGameMode(msg.ModeId)

   ```

   -- ✅ CORRECT: Individual handler per action
   Handlers.add("create-game-mode",

   -- ❌ FORBIDDEN: Direct assignment
   Handlers["CreateGameMode"] = function(msg) ... end
   ```

   -- ✅ CORRECT: Use message timestamp
   local timestamp = msg.Timestamp or 0

   -- ❌ FORBIDDEN: os.time() in AO processes

   -- ✅ CORRECT: Simple parameters in tags

   ```
