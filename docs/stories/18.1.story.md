#### Starter Pokemon Selection Algorithm (src/data/daily-run.ts:27-62)
**Purpose**: Generate 3 starter Pokemon with controlled cost distribution

**Algorithm Steps**:

1. **Check Event Seed Starters** (lines 34-38)
   - If seed contains `/starters\d{18}/` pattern, parse custom starters
   - Format: `/starters{speciesId1:4}{formIndex1:2}{speciesId2:4}{formIndex2:2}{speciesId3:4}{formIndex3:2}/`
   - Example: `/starters000100000002000000030000/` → Species 1 form 0, Species 2 form 0, Species 3 form 0
   - If event starters found, return them and skip cost-based generation

2. **Cost Distribution Generation** (lines 40-43)
   - **Cost 1**: `Math.min(Math.round(3.5 + Math.abs(randSeedGauss(1))), 8)`
     - Gaussian distribution around 3.5, capped at 8
     - randSeedGauss(1) uses mean=0, stdDev=1
     - Typical values: 3-5 (common), 6-8 (rare)
   - **Cost 2**: `randSeedInt(9 - cost1, 1)`
     - Random integer between 1 and (9 - cost1)
     - Ensures cost1 + cost2 ≤ 9
   - **Cost 3**: `10 - (cost1 + cost2)`
     - Remainder to ensure total = 10
   - **Constraint**: All three costs sum to exactly 10

3. **Species Selection** (lines 45-54)
   - For each cost value:
     - Filter speciesStarterCosts table for matching cost
     - Example: cost=5 → [Pikachu, Eevee, Vulpix, ...] (species with cost 5)
     - Select random species: `randSeedItem(costSpecies)`
     - Get trainer-appropriate form: `getTrainerSpeciesForLevel(20, true, PartyMemberStrength.STRONGER)`
     - Create starter with dexAttr, abilityIndex, nature, pokerus

4. **Starter Object Creation** (lines 64-79)
   - Create temporary Pokemon instance at starting level (20 for daily)
   - Extract attributes: dexAttr, abilityIndex, nature, pokerus
   - Destroy temporary Pokemon (cleanup)
   - Return Starter object with extracted data

**Key Insight**: Gaussian distribution for first cost ensures variety while preventing extremes (no cost=1+1+8 scenarios)

#### Biome Selection Algorithm (src/data/daily-run.ts:129-158)
**Purpose**: Select starting biome using weighted random selection

**Algorithm Steps**:

1. **Check Event Seed Biome** (lines 130-133)
   - If seed contains `/biome\d{2}/` pattern, parse custom biome
   - Format: `/biome{biomeId:2}/` (zero-padded)
   - Example: `/biome05/` → BiomeId.CAVE (5)
   - If event biome found, return it and skip weighted selection

2. **Filter Available Biomes** (line 135)
   - Exclude BiomeId.TOWN (0) and BiomeId.END (last biome)
   - All other biomes eligible for daily run start

3. **Weighted Selection Setup** (lines 137-145)
   - **dailyBiomeWeights** (lines 88-127): Predefined weight table
     - Weight 3 (high frequency): CAVE, LAKE, PLAINS, SNOWY_FOREST, SWAMP, TALL_GRASS
     - Weight 2 (medium frequency): 17 biomes (ABYSS, RUINS, BADLANDS, BEACH, etc.)
     - Weight 1 (low frequency): GRAVEYARD, ICE_CAVE, ISLAND, JUNGLE, LABORATORY, METROPOLIS, POWER_PLANT, SPACE, WASTELAND
     - Weight 0 (never): TOWN, END
   - **Algorithm**:
     - Calculate totalWeight = sum of all biome weights
     - Build cumulative threshold array: biomeThresholds[i] = sum(weights[0..i])
     - Example: weights [3, 2, 1] → thresholds [3, 5, 6], totalWeight = 6

4. **Random Selection** (lines 147-153)
   - Generate random integer: `randInt = randSeedInt(totalWeight)`
   - Find first biome where `randInt < biomeThresholds[i]`
   - Example: totalWeight=50, randInt=27, thresholds=[3, 5, 8, 10, 13, 16, 18, 20, 22, 25, 27, 30, ...]
     - randInt=27 < biomeThresholds[10]=30 → return biomes[10]

5. **Fallback** (lines 156-157)
   - If no match found (should never happen): `randSeedInt(biomes.length)`

**Key Insight**: Weighted selection ensures variety while favoring larger/popular biomes (weight 3)

#### Daily Run Difficulty Scaling (src/game-mode.ts:161-168)
**Purpose**: Adjust effective wave difficulty for daily runs

**TypeScript Formula**:
```typescript
getWaveForDifficulty(waveIndex: number, ignoreCurveChanges = false): number {
  switch (this.modeId) {
    case GameModes.DAILY:
      return waveIndex + 30 + (!ignoreCurveChanges ? Math.floor(waveIndex / 5) : 0);
    default:
      return waveIndex;
  }
}
```

**Algorithm**:
- Base offset: +30 effective waves (wave 1 difficulty = classic wave 31)
- Progression bonus: +1 effective wave per 5 waves completed
- Example calculations:
  - Wave 1: 1 + 30 + floor(1/5) = 31 (no progression bonus)
  - Wave 5: 5 + 30 + floor(5/5) = 36 (1 bonus wave)
  - Wave 10: 10 + 30 + floor(10/5) = 42 (2 bonus waves)
  - Wave 25: 25 + 30 + floor(25/5) = 60 (5 bonus waves)
- ignoreCurveChanges parameter: Used for specific calculations that need base difficulty

**Key Insight**: Accelerating difficulty curve makes later waves harder faster than classic mode

#### Daily Run Trainer Spawn Logic (src/game-mode.ts:176-211)
**Purpose**: Determine which waves spawn trainers in daily runs

**TypeScript Logic**:
```typescript
if (this.isDaily) {
  return waveIndex % 10 === 5 || (!(waveIndex % 10) && waveIndex > 10 && !this.isWaveFinal(waveIndex));
}
```

**Algorithm**:
- **Condition 1**: `waveIndex % 10 === 5` → Waves 5, 15, 25, 35, 45 (every X5 wave)
- **Condition 2**: `!(waveIndex % 10) && waveIndex > 10 && !this.isWaveFinal(waveIndex)`
  - Waves divisible by 10 (X0 waves)
  - After wave 10 (excludes wave 10 itself)
  - Not final wave (wave 50 excluded if final)
  - Result: Waves 20, 30, 40 (every X0 wave except 10 and final)
- **Combined**: Waves 5, 15, 20, 25, 30, 35, 40, 45 spawn trainers

**Classic Mode Comparison** (lines 183-200):
- Trainers on waves X0 (every 10th wave, gym leaders)
- Trainers on waves X5 (optional, based on arena trainerChance)
- Daily mode has fixed trainer waves regardless of arena

**Key Insight**: Fixed trainer schedule ensures consistent daily run experience

#### Event Seed Parsing (src/data/daily-run.ts:166-281)
**Purpose**: Parse custom event modifiers from extended seed strings

**Event Seed Format**:
- Standard seed: 24 characters (example: "20250103abcdefghij123456")
- Event seed: 24+ characters with `/modifier/` tags
- Example: "20250103abcdefghij123456/starters000100000002000300010000/boss000400/biome05/luck08"

**Modifier Patterns**:

1. **isDailyEventSeed()** (lines 166-168)
   - Check: `seed.length > 24`
   - Returns: true if extended seed

2. **Starters Modifier** (lines 176-204)
   - Pattern: `/starters(\d{4})(\d{2})(\d{4})(\d{2})(\d{4})(\d{2})/`
   - Format: 3 sets of {speciesId:4 digits}{formIndex:2 digits}
   - Example: `/starters000100000002000000030000/`
     - Starter 1: Species 1 (Bulbasaur), form 0
     - Starter 2: Species 2 (Ivysaur), form 0
     - Starter 3: Species 3 (Venusaur), form 0
   - Validation: Species ID must exist in SpeciesId enum
   - Error handling: Return null if invalid, fall back to cost-based generation

3. **Boss Modifier** (lines 212-232)
   - Pattern: `/boss(\d{4})(\d{2})/`
   - Format: {speciesId:4 digits}{formIndex:2 digits}
   - Example: `/boss000100/` → Species 1 (Bulbasaur), form 0
   - Validation: Species ID must exist
   - Error handling: Return null if invalid, use default boss

4. **Biome Modifier** (lines 238-256)
   - Pattern: `/biome(\d{2})/`
   - Format: {biomeId:2 digits} (zero-padded)
   - Example: `/biome05/` → BiomeId.CAVE (5)
   - Validation: Biome ID must exist in BiomeId enum
   - Error handling: Return null if invalid, use weighted selection

5. **Luck Modifier** (lines 263-281)
   - Pattern: `/luck(\d{2})/`
   - Format: {luckValue:2 digits} (zero-padded, range 0-14)
   - Example: `/luck08/` → luck value 8
   - Validation: Must be 0 ≤ luck ≤ 14
   - Error handling: Return null if invalid, use default luck

**Key Insight**: Event seeds allow special daily runs with curated content (holiday events, challenges)
