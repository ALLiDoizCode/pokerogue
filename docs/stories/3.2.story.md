### Data Models
**Pokemon Instance Data Structure** [Source: architecture/data-models.md#Pokemon Model]:
```lua
PokemonInstance = {
  -- Instance identification
  id = number,                    -- Unique Pokemon instance identifier
  speciesId = string,            -- Species identifier from SpeciesId enum
  
  -- Core attributes
  level = number,                -- Current Pokemon level (1-100)
  exp = number,                  -- Total experience points
  
  -- Health and stats
  hp = number,                   -- Current hit points
  maxHp = number,               -- Maximum hit points at current level
  stats = {                     -- Current battle stats [HP, ATK, DEF, SPATK, SPDEF, SPEED]
    hp = number,
    attack = number,
    defense = number,
    spatk = number,
    spdef = number,
    speed = number
  },
  
  -- Genetic data
  ivs = {                       -- Individual values for stat calculation
    hp = number,                -- 0-31 range
    attack = number,
    defense = number,
    spatk = number,
    spdef = number,
    speed = number
  },
  nature = string,              -- Nature affecting stat growth
  personality = number,         -- 32-bit personality value for shiny/gender/etc
  
  -- Abilities and moves
  moveset = table,              -- Array of PokemonMove objects
  abilities = table,            -- Available abilities and current selection
  
  -- Status and items
  statusEffect = string|nil,    -- Current status condition
  heldItem = string|nil,        -- Currently held item identifier
  
  -- Battle and temporary data
  battleData = table,           -- Temporary battle-specific data
  
  -- Metadata
  originalTrainer = string,     -- Original trainer ID/address
  captured = number,            -- Timestamp when captured
  nickname = string|nil         -- Custom nickname if assigned
}
```

**Pokemon Relationships** [Source: architecture/data-models.md#Pokemon Model]:
- Belongs to Player (via party roster)
- References Species data (via speciesId) from pokemon-species-db.lua
- Contains Move data (via moveset array)
- Links to Battle data (when actively battling)

### Process Implementation Requirements
**AO Process Constraints** [Source: architecture/tech-stack.md#Process Implementation Requirements]:
- Monolithic Design: All dependencies embedded in single file, no require() statements
- Handler Pattern: Use Handlers.add() with tag matching, not direct assignment
- Error Handling: All operations wrapped in pcall with structured error responses
- Size Limit: 500KB maximum per process file
- Execution Timeout: 5-second limit per message handler

**AO Globals Available** [Source: architecture/tech-stack.md#Available AO Globals]:
- `ao.send()` - Message transmission to other processes
- `ao.id` - Process identifier
- `Handlers` - Message routing with Handlers.add(name, matcher, handler)
- `json` - Data serialization for encode/decode
- Standard Lua: string, table, math, os (limited subset)

### API Specifications
**Handler Message Schemas**:

```lua
-- CreatePokemon Handler
Request: {
  Action = "CreatePokemon",
  Data = {
    speciesId = number,           -- Species ID (required)
    level = number,               -- Initial level (default: 5)
    forceShiny = boolean,         -- Force shiny generation (optional, testing only)
    forcedIVs = table,            -- Override IV generation (optional, testing only)
    forcedNature = string         -- Override nature (optional, testing only)
  },
  Timestamp = number
}
Response: {
  Action = "PokemonCreated",
  Data = {
    success = boolean,
    pokemon = PokemonInstance,    -- Complete Pokemon instance data
    error = string (on failure)
  }
}

-- UpdatePokemonState Handler
Request: {
  Action = "UpdatePokemonState",
  Data = {
    pokemonId = number,           -- Pokemon instance ID
    modifications = {
      level = number,             -- New level (optional)
      exp = number,               -- Experience change (optional)
      hp = number,                -- Current HP change (optional)
      statusEffect = string       -- Status effect change (optional)
    }
  },
  Timestamp = number
}
Response: {
  Action = "PokemonStateUpdated",
  Data = {
    success = boolean,
    pokemon = PokemonInstance,    -- Updated Pokemon instance
    changes = table,              -- Summary of applied changes
    error = string (on failure)
  }
}

-- GetPokemonInstance Handler
Request: {
  Action = "GetPokemonInstance",
  Data = {
    pokemonId = number            -- Pokemon instance ID
  },
  Timestamp = number
}
Response: {
  Action = "PokemonInstanceData",
  Data = {
    success = boolean,
    pokemon = PokemonInstance,    -- Complete Pokemon instance data
    error = string (on failure)
  }
}

-- SerializePokemon Handler
Request: {
  Action = "SerializePokemon",
  Data = {
    pokemonId = number            -- Pokemon instance ID
  },
  Timestamp = number
}
Response: {
  Action = "PokemonSerialized",
  Data = {
    success = boolean,
    serialized = string,          -- Base64 encoded Pokemon data
    checksum = string,            -- Data integrity checksum
    error = string (on failure)
  }
}

-- DeserializePokemon Handler
Request: {
  Action = "DeserializePokemon",
  Data = {
    serialized = string,          -- Base64 encoded Pokemon data
    checksum = string             -- Data integrity checksum
  },
  Timestamp = number
}
Response: {
  Action = "PokemonDeserialized",
  Data = {
    success = boolean,
    pokemon = PokemonInstance,    -- Restored Pokemon instance
    pokemonId = number,           -- Assigned Pokemon ID
    error = string (on failure)
  }
}
```
