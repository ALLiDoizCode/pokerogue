### API Specifications

**Handler: SearchPokedex** [Source: Analysis of src/ui/pokedex-ui-handler.ts updateStarters() logic]
- **Trigger Tag**: `Action = "SearchPokedex"`
- **Required Parameters**: `msg.Data` (JSON with searchQuery: textSearch, filters, sort)
- **Response**: Search results with matching species, relevance scores, filter metadata
- **Workflow**: Parse query → Apply text search → Apply filters → Sort results → Return paginated results
- **Special Cases**: Empty results provide search suggestions, fuzzy matching for typos
- **Example**:
  ```lua
  -- Request
  {
    Action = "SearchPokedex",
    Data = json.encode({
      textSearch = {name = "pika"},
      filters = {generation = {1}, types = {13}},
      sort = {criteria = "NAME", direction = -1}
    })
  }

  -- Response
  {
    Action = "SaveState",
    Success = "true",
    Data = json.encode({
      species = {{speciesId = 25, name = "Pikachu", matchScore = 100, matchReason = "Exact name match"}},
      totalCount = 1,
      filteredCount = 1,
      appliedFilters = {generation = {1}, types = {13}, textSearch = "pika"}
    })
  }
  ```

**Handler: ApplyFilters** [Source: src/ui/pokedex-ui-handler.ts updateStarters() filtering sections]
- **Trigger Tag**: `Action = "ApplyFilters"`
- **Required Parameters**: `msg.Data` (JSON with filter criteria by category)
- **Response**: Filtered species list with applied filter metadata
- **Workflow**: Load all species → Apply generation filter → Apply type filter → Apply biome filter → Apply caught filter → Apply unlocks filter → Apply misc filter → Return results
- **Special Cases**: Empty filter = no filtering for that category, EXCLUDE state removes matching species
- **Example**:
  ```lua
  -- Request
  {
    Action = "ApplyFilters",
    Data = json.encode({
      filters = {
        generation = {1, 3},
        types = {6, 10},  -- Fire or Water
        caught = "SHINY"
      }
    })
  }

  -- Response
  {
    Action = "SaveState",
    Success = "true",
    Data = json.encode({
      filteredSpecies = {{speciesId = 6, name = "Charizard"}, {speciesId = 9, name = "Blastoise"}},
      totalCount = 2,
      appliedFilters = {generation = {1, 3}, types = {6, 10}, caught = "SHINY"}
    })
  }
  ```

**Handler: SortResults** [Source: src/ui/pokedex-ui-handler.ts updateStarters() sort section]
- **Trigger Tag**: `Action = "SortResults"`
- **Required Parameters**: `msg.Data` (JSON with species list and sort criteria)
- **Response**: Sorted species list with sort metadata
- **Workflow**: Parse sort criteria → Apply sort algorithm → Maintain stable sort for equal values → Return sorted results
- **Example**:
  ```lua
  -- Request
  {
    Action = "SortResults",
    Data = json.encode({
      species = {{speciesId = 25, name = "Pikachu", cost = 3}, {speciesId = 1, name = "Bulbasaur", cost = 2}},
      sort = {criteria = "COST", direction = 1}  -- DESC
    })
  }

  -- Response
  {
    Action = "SaveState",
    Success = "true",
    Data = json.encode({
      sortedSpecies = {{speciesId = 25, name = "Pikachu", cost = 3}, {speciesId = 1, name = "Bulbasaur", cost = 2}},
      sortCriteria = "COST",
      sortDirection = 1
    })
  ```

```lua
-- Search and filter pattern: process queries and return filtered/sorted results

local json = require("json")

-- Constants
local DROPDOWN_TYPES = {
  SINGLE = 0,
  MULTI = 1,
  HYBRID = 2,
  RADIAL = 3
}

local DROPDOWN_STATES = {
  ON = 0,
  OFF = 1,
  EXCLUDE = 2,
  UNLOCKABLE = 3,
  ONE = 4,
  TWO = 5
}

local SORT_CRITERIA = {
  NUMBER = 0,
  COST = 1,
  CANDY = 2,
  IV = 3,
  NAME = 4,
  CAUGHT = 5,
  HATCHED = 6
}

-- Helper functions for search and filtering
local function searchSpeciesByName(speciesData, searchTerm)
  local results = {}
  local lowerTerm = string.lower(searchTerm)

  for _, species in ipairs(speciesData) do
    local lowerName = string.lower(species.name)
    if string.find(lowerName, lowerTerm, 1, true) then
      table.insert(results, {
        species = species,
        matchScore = 100,
        matchReason = "Name match"
      })
    end
  end

  return results
end

local function applyGenerationFilter(speciesData, generations)
  if #generations == 0 then return speciesData end

  local filtered = {}
  for _, species in ipairs(speciesData) do
    for _, gen in ipairs(generations) do
      if species.generation == gen then
        table.insert(filtered, species)
        break
      end
    end
  end

  return filtered
end

local function sortSpecies(speciesData, criteria, direction)
  local sorted = {table.unpack(speciesData)}

  table.sort(sorted, function(a, b)
    if criteria == SORT_CRITERIA.NUMBER then
      return (a.speciesId - b.speciesId) * direction < 0
    elseif criteria == SORT_CRITERIA.NAME then
      return (string.lower(a.name) < string.lower(b.name)) == (direction == -1)
    end
    -- ... other criteria
  end)

  return sorted
end

-- Handler registration (individual handlers for each action)
Handlers.add("search-pokedex",
  Handlers.utils.hasMatchingTag("Action", "SearchPokedex"),
  function(msg)
    local data = json.decode(msg.Data or "{}")

    if not data.textSearch and not data.filters then
      ao.send({
        Target = msg.From,
        Action = "Error",
        Error = "Search query or filters required"
      })
      return
    end

    -- Search logic
    local results = performSearch(data)

    ao.send({
      Target = msg.From,
      Action = "SaveState",
      Success = "true",
      Data = json.encode(results)
    })
  end
)
```

**AO Runtime Constraints** [Source: docs/architecture/tech-stack.md#performance-constraints]

- Estimated Process Size: ~50-60KB for search, filter, sort, export functionality

**AO Compliance Requirements** [Source: docs/architecture/tech-stack.md#process-implementation-requirements]
- Monolithic Design: All search and filter logic in single file
- Handler Pattern: Use `Handlers.add()` with individual handlers per action (no multi-action handlers)
- Error Handling: Direct validation and error responses, avoid unnecessary pcall usage
- **CRITICAL**: Never use pcall for simple data access (table lookups, parameter validation, string operations)
- **CRITICAL**: Use pcall ONLY for operations that genuinely might fail (external JSON parsing from untrusted sources)
- Available Globals: ao.send(), ao.id, Handlers, json, standard Lua (string, table, math)

**Forbidden Operations** [Source: CLAUDE.md#ao-process-implementation-guidelines]
- `require()` - No external module loading (except require("json") which is permitted)
- `os.time()` - Use `msg.Timestamp` instead
- `io` - No file system access
- `debug` - Debug library unavailable
- Network operations - Only through ao.send()

**Coding Standards** [Source: docs/architecture/coding-standards.md]
- Functions: camelCase (e.g., `searchPokedex()`, `applyFilters()`)
- Variables: camelCase (e.g., `filteredSpecies`, `sortCriteria`)
- Constants: UPPER_SNAKE_CASE (e.g., `SORT_CRITERIA`, `DROPDOWN_TYPES`)
- Tables/Objects: PascalCase (e.g., `SearchQuery`, `FilterCriteria`)
- Files: kebab-case (e.g., `advanced-pokedex-features-engine.lua`)
- All message responses must include Success tag: `Success = "true"` or `Success = "false"`

**Deterministic Behavior Requirements**
- All search operations must be predictable and reproducible
- Filter application must be consistent across executions
- Sort order must be deterministic for equal values (stable sort)
- Export formats must be validated and accurate

**Performance Considerations**
- Pagination for large result sets (>100 species)
- Result caching for frequent searches (optional optimization)
- Efficient string matching algorithms (avoid nested loops)
- Filter short-circuit optimization (stop early if no matches)
