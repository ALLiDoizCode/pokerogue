# Story 6.1: Pokemon Status Condition Migration

**Epic:** Epic 6 - Status Effects & Environmental Systems  
**Status:** Done  
**Created:** September 25, 2025  
**Assigned:** Status Effect Engineering Team  

## Story Statement
As a **status effect engineer**,  
I want **all Pokemon status conditions migrated to stateless AO process**,  
so that **status application, duration, and effects maintain identical behavior to TypeScript**.

## Acceptance Criteria
1. All major status conditions (sleep, paralysis, burn, freeze, poison) apply identical effects
2. Status condition duration tracking maintains identical turn counting and probability distributions
3. Status effect damage calculations produce mathematically identical results
4. Status condition removal and cure mechanics maintain identical trigger conditions
5. Status condition interaction with abilities and items maintains identical priority and behavior
6. Complex status interactions (multiple conditions, immunity) behave identically to TypeScript
7. Status condition battle message generation maintains identical text and timing
8. Comprehensive testing validates 100% status effect behavioral parity

### API Specifications
**Message Protocol** [Source: architecture/tech-stack.md#46-68]:
```lua
-- Incoming Message Structure for Status Operations
msg = {
    Action = "ProcessLogic",
    Data = {
        operation = "applyStatusEffect", -- or "processStatusTurn", "removeStatusEffect"
        gameState = {
            pokemon = { hp, maxHp, statusEffect, toxicTurnCount, sleepTurnsRemaining },
            battleSeed = "deterministic_seed"
        },
        parameters = {
            statusType = "toxic", -- Using TypeScript names: poison, toxic, burn, etc.
            targetId = "pokemon_id"
        }
    },
    Timestamp = msg.Timestamp or 0
}

-- Response Structure with Status Data
ao.send({
    Target = msg.From,
    Action = "SaveState",
    Data = json.encode({
        success = true,
        statusEffect = "toxic",
        toxicTurnCount = 1,  -- For TOXIC status
        sleepTurnsRemaining = 3,  -- For SLEEP status
        damage = 125,  -- Calculated damage
        message = "Pokemon was badly poisoned!"
    }),
    Error = error_message, -- Optional
    ProcessId = ao.id,
    Timestamp = tostring(msg.Timestamp or 0)
})
```

**Handler Registration Pattern** [Source: CLAUDE.md - AO Process Implementation Guidelines]:
- MUST use individual handlers for each action (no multi-action handlers)
- Use Handlers.add() with tag matching, never direct assignment
- Wrap operations in pcall only when they might fail (not for simple lookups)
