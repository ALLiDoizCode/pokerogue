### Testing Standards
**Location**: `testing/unit/*.test.lua`

**Framework**: Real aolite framework (NOT mock-aolite)

**Correct Aolite API Pattern** (from `.ai/correct-aolite-test-pattern.lua`):
```lua
-- 1. Read process source
local file = io.open(PROCESS_PATH, "r")
if not file then error("Failed to open: " .. PROCESS_PATH) end
local processSource = file:read("*all")
file:close()

-- 2. Spawn process (returns nothing)
local processId = "test-my-process"
aolite.spawnProcess(processId, processSource, {{ name = "On-Boot", value = "Data" }})

-- 3. Send message and retrieve response (separate operations)
local function sendMessage(action, tags, data)
    local msg = {
        From = processId,      -- REQUIRED
        Target = processId,    -- REQUIRED
        Action = action,
        Data = data or ""
    }
    if tags then
        for k, v in pairs(tags) do msg[k] = tostring(v) end
    end
    aolite.send(msg)
    return aolite.getLastMsg(processId)  -- Retrieve response separately
end
```

**Linear Execution Pattern** (NO describe/it):
- Tests execute sequentially, top-to-bottom
- Use `print()` for test output with emojis: 📝 (test start), ✅ (pass), ❌ (fail)
- Use `error()` for test failures with explicit messages
- Single process spawn per file
- No before_each/after_each (inline setup at file start)

**Migration Transformation Rules**:
1. **describe/it removal**: Convert to linear print() statements
2. **Assertion conversion**: `assert.*` → `error()` with explicit messages
3. **Setup inlining**: Move `before_each` logic to file start
4. **Cleanup removal**: Delete `after_each` (not needed)
5. **Process spawn**: Single `aolite.spawnProcess()` per file
6. **Message pattern**: Always include `From: processId` in messages

**Handler Inspection**:
- Use `scripts/inspect-process-handlers.sh` to discover action names
- Document expected action response names (e.g., `SaveState`, `Error`, `Info-Response`)
- Watch for consolidated processes (multiple test files → single process file)

**Common Pitfalls to Avoid**:
- ❌ OLD API: `local process = aolite.spawnProcess(PROCESS_PATH)` (returns object)
- ❌ OLD API: `Target = process.id` (process.id doesn't exist)
- ❌ OLD API: `return aolite.send(msg)` (doesn't return response)
- ✅ NEW API: `aolite.spawnProcess(processId, source, tags)` → returns nothing
- ✅ NEW API: `From = processId, Target = processId` → both required
- ✅ NEW API: `aolite.send(msg); return aolite.getLastMsg(processId)` → separate retrieval
