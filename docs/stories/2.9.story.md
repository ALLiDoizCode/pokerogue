## Dev Notes

### State Isolation Pattern (Story 2.8 Lesson)
**Problem**: Processes maintain cumulative state across tests

**Solution**: Use unique entity IDs for test isolation
```lua
-- ❌ BAD: Shares default player state
sendMessage("UpdatePlayerLevel", {
    ExperienceGained = "1000"
})

-- ✅ GOOD: Isolated player state
sendMessage("UpdatePlayerLevel", {
    PlayerId = "test-scenario-1",
    ExperienceGained = "1000"
})
```

**When to Use**:
- Tests with precise value assertions (level calculations, stat values)
- Tests that must be independent of execution order
- Tests validating specific game states

**When NOT Needed**:
- Tests validating error handling
- Tests checking response structure/format
- Tests that intentionally build state sequentially

### Correct Aolite API Pattern
```lua
-- 1. Read process source
local file = io.open(PROCESS_PATH, "r")
local processSource = file:read("*all")
file:close()

-- 2. Spawn process (returns nothing)
local processId = "test-process-name"
aolite.spawnProcess(processId, processSource, spawnTags)

-- 3. Send message and retrieve response
local function sendMessage(action, tags, data)
    local msg = {
        From = processId,    -- REQUIRED
        Target = processId,  -- REQUIRED
        Action = action,
        Data = data or ""
    }
    if tags then
        for k, v in pairs(tags) do msg[k] = tostring(v) end
    end
    aolite.send(msg)
    return aolite.getLastMsg(processId)
end
```

**Critical Issue Identified:**
- ⚠️ **INEFFICIENT PROCESS SPAWNING**: All 6 test files (and 97 total across project) manually read process files with `io.open()` → `file:read("*all")` before passing to aolite, when aolite can load files directly

**Inefficient Pattern (Current):**
```lua
-- ❌ INEFFICIENT: Manually reading file
local file = io.open(PROCESS_PATH, "r")
local processSource = file:read("*all")
file:close()
local spawnTags = { { name = "On-Boot", value = "Data" } }
aolite.spawnProcess(processId, processSource, spawnTags)
```

**Correct Pattern (Should Use):**
```lua
-- ✅ EFFICIENT: Let aolite load the file
aolite.spawnProcess(processId, "processes/my-process")  -- No .lua extension, no tags needed
```

**Impact:**
- **Performance**: Unnecessary file I/O operations in every test file
- **Code Maintenance**: Extra 4-5 lines of boilerplate per test file
- **Systemic Scope**: Affects 97 test files across the entire project
- **Reference Template**: Even `.ai/correct-aolite-test-pattern.lua` has this wrong pattern
