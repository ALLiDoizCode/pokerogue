**Dialogue Flow Pattern:**
[Source: src/data/mystery-encounters/mystery-encounter-dialogue.ts:27-69]

```
1. intro dialogue (array of TextDisplay) - Can be messages or speaker dialogue
2. encounterOptionsDialogue - Present choices to player
   - title: Displayed at top
   - description: Explanation of situation
   - query: Question for player
   - options[]: Array of choices (minimum 2)
3. Player selects option
4. option.selected dialogue (array of TextDisplay) - Reaction to choice
5. option.onPreOptionPhase() - Calculate dialogue tokens
6. option.onOptionPhase() - Execute choice logic
7. option.onPostOptionPhase() - Post-execution logic
8. outro dialogue (array of TextDisplay) - Closing messages
```

### API Specifications

**Process: dialogue-navigation-engine.lua**

**Handler: GetDialogueFlow**
- **Input Tags:** EncounterType, DialoguePhase (intro/options/selected/outro), Data (JSON: encounter definition)
- **Output Tags:** PhaseType (intro/options/selected/outro), Success (true/false), Error (if validation fails)
- **Output Data:** JSON dialogue content for requested phase
- **Purpose:** Retrieve dialogue content for specific phase of encounter

**Handler: ValidateOptionSelection**
- **Input Tags:** EncounterType, OptionIndex, Data (JSON: gameState)
- **Output Tags:** Valid (true/false), OptionEnabled (true/false), RequirementsMet (true/false), Error (if validation fails)
- **Output Data:** JSON validation result with failed requirements list
- **Purpose:** Validate if player can select specific option based on requirements

**Handler: ProcessDialogueTokens**
- **Input Tags:** DialogueText, Data (JSON: dialogueTokens map)
- **Output Tags:** Success (true/false), TokenCount (number of replacements made)
- **Output Data:** Processed text with tokens replaced
- **Purpose:** Replace {{tokenName}} placeholders with actual values

**Handler: GetOptionConsequences**
- **Input Tags:** EncounterType, OptionIndex, Data (JSON: gameState)
- **Output Tags:** HasConsequences (true/false), ConsequenceType (immediate/deferred), Success (true/false)
- **Output Data:** JSON consequence definition (rewards, penalties, state changes)
- **Purpose:** Calculate consequences of selecting specific option

**Handler: TrackDialogueChoice**
- **Input Tags:** EncounterType, OptionIndex, Data (JSON: dialogueHistory)
- **Output Tags:** ChoiceRecorded (true/false), TotalChoices (number), Success (true/false)
- **Output Data:** Updated dialogue history JSON
- **Purpose:** Record player choice for narrative continuity tracking

**Handler: Info** (ADP v1.0 Compliance)
- **Input Tags:** Action = "Info"
- **Output Tags:** Success = "true"
- **Output Data:** JSON process metadata
- **Purpose:** Self-documentation for ADP v1.0 compliance

### Implementation Guidance

**Dialogue Flow State Machine:**
[Source: src/phases/mystery-encounter-phases.ts:29-330]

TypeScript uses phase-based flow control:
```typescript
// Phase progression:
MysteryEncounterPhase -> displays intro dialogue and options
  ↓ (player selects option)
MysteryEncounterOptionSelectedPhase -> displays option.selected dialogue
  ↓
MysteryEncounterBattlePhase / LeaveEncounter -> execute option logic
  ↓
MysteryEncounterRewardsPhase -> distribute rewards
  ↓
PostMysteryEncounterPhase -> displays outro dialogue
```

**Lua Implementation Strategy:**

For stateless AO process, implement flow as state machine:
```lua
local DIALOGUE_PHASES = {
  INTRO = "intro",
  OPTIONS = "options",
  SELECTED = "selected",
  OUTRO = "outro"
}

local function getDialogueFlow(encounterType, phase, encounterDefinition)
  if phase == DIALOGUE_PHASES.INTRO then
    return encounterDefinition.dialogue.intro or {}
  elseif phase == DIALOGUE_PHASES.OPTIONS then
    return encounterDefinition.dialogue.encounterOptionsDialogue or {}
  elseif phase == DIALOGUE_PHASES.SELECTED then
    -- Requires optionIndex to know which option's selected dialogue to show
    return encounterDefinition.options[optionIndex].dialogue.selected or {}
  elseif phase == DIALOGUE_PHASES.OUTRO then
    return encounterDefinition.dialogue.outro or {}
  end
end
```

**Dialogue Token Replacement:**
[Source: src/data/mystery-encounters/utils/encounter-dialogue-utils.ts:14-45]

TypeScript uses i18n interpolation with tokens:
```typescript
function getTextWithDialogueTokens(keyOrString: string): string {
  const tokens = scene.currentBattle?.mysteryEncounter?.dialogueTokens;

  if (i18next.exists(keyOrString, tokens)) {
    return i18next.t(keyOrString, tokens); // Replaces {{tokenName}} with values
  }

  return keyOrString;
}
```

**Lua Implementation:**
```lua
local function processDialogueTokens(text, dialogueTokens)
  local processedText = text
  local tokenCount = 0

  -- Replace {{tokenName}} with values from dialogueTokens map
  for tokenName, tokenValue in pairs(dialogueTokens) do
    local pattern = "{{" .. tokenName .. "}}"
    local replacedText = string.gsub(processedText, pattern, tokenValue)
    if replacedText ~= processedText then
      tokenCount = tokenCount + 1
      processedText = replacedText
    end
  end

  return processedText, tokenCount
end
```
