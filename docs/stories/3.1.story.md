## Story Statement
As a **data migration engineer**,  
I want **complete Pokemon species database with stats, types, and evolution data migrated to stateless AO process**,  
so that **species queries maintain identical performance and data integrity as TypeScript implementation**.

## Acceptance Criteria
1. Stateless AO process provides complete species database with identical data structure to TypeScript implementation
2. Species query performance matches or exceeds TypeScript reference implementation benchmarks
3. Type effectiveness calculations produce mathematically identical results across all type combinations
4. Evolution chain data maintains complete accuracy including conditional evolution requirements
5. Base stat calculations for all 1000+ Pokemon species produce identical results to TypeScript
6. Move learning data maintains complete accuracy including level-up, TM, and breeding moves
7. Bundle size optimization stores large species data externally via Arweave references
8. Comprehensive unit testing validates 100% data parity against TypeScript species database

### Process Implementation Requirements
**AO Process Constraints** [Source: architecture/tech-stack.md#Process Implementation Requirements]:
- Monolithic Design: All dependencies embedded in single file, no require() statements
- Handler Pattern: Use Handlers.add() with tag matching, not direct assignment
- Error Handling: All operations wrapped in pcall with structured error responses
- Size Limit: 500KB maximum per process file
- Execution Timeout: 5-second limit per message handler

**AO Globals Available** [Source: architecture/tech-stack.md#Available AO Globals]:
- `ao.send()` - Message transmission to other processes
- `ao.id` - Process identifier
- `Handlers` - Message routing with Handlers.add(name, matcher, handler)
- `json` - Data serialization for encode/decode
- Standard Lua: string, table, math, os (limited subset)

### API Specifications
**Handler Message Schemas**:

```lua
-- GetSpecies Handler
Request: {
  Action = "GetSpecies",
  Data = {
    id = number (optional),     -- Species ID (e.g., 6 for Charizard)
    name = string (optional)    -- Species name (e.g., "Charizard")
  },
  Timestamp = number
}
Response: {
  Action = "SpeciesData",
  Data = {
    success = boolean,
    species = {
      id = number,
      name = string,
      baseStats = {hp, atk, def, spatk, spdef, spd},
      types = {type1, type2 or nil},
      abilities = {normal1, normal2 or nil, hidden or nil},
      height = number,
      weight = number,
      evolutionChain = {...}
    },
    error = string (on failure)
  }
}

-- GetEvolutionChain Handler  
Request: {
  Action = "GetEvolutionChain",
  Data = { speciesId = number },
  Timestamp = number
}
Response: {
  Action = "EvolutionChainData",
  Data = {
    success = boolean,
    chain = {
      from = speciesId or nil,
      to = {speciesId, level, conditions} or nil,
      branches = {...} or nil
    },
    error = string (on failure)
  }
}

-- GetBaseStats Handler
Request: {
  Action = "GetBaseStats",
  Data = { speciesId = number },
  Timestamp = number  
}
Response: {
  Action = "BaseStatsData",
  Data = {
    success = boolean,
    stats = {hp, atk, def, spatk, spdef, spd},
    total = number,
    error = string (on failure)
  }
}

-- GetTypeEffectiveness Handler
Request: {
  Action = "GetTypeEffectiveness",
  Data = {
    attackType = string,
    defenseTypes = {type1, type2 or nil}
  },
  Timestamp = number
}
Response: {
  Action = "TypeEffectivenessData",
  Data = {
    success = boolean,
    multiplier = number (0.25, 0.5, 1, 2, 4),
    error = string (on failure)
  }
}
```
