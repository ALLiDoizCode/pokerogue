### Regression Testing

**Scope:** Verify daily run engine doesn't break existing Epic 16 biome system.

**Test Cases:**
1. **Process Coexistence**
   - Load `biome-progression-engine.lua` (Epic 16)
   - Load `daily-run-engine.lua` (Epic 18)

   - Verify no global state pollution

2. **Biome System Compatibility**
   - Call Epic 16 biome transition: `TransitionToBiome` handler
   - Verify biome progression still works correctly
   - Call daily run biome selection: `GenerateDailyRun` handler
   - Verify daily run returns valid biome from same BiomeId range

3. **State Isolation**
   - Generate daily run (creates internal RNG state)
   - Call Epic 16 biome transition (uses separate RNG)
   - Verify no cross-process state leakage
   - Verify deterministic behavior maintained in both

4. **Biome ID Range Validation**
   - Both processes use BiomeId 0-34
   - Daily run excludes TOWN (0) and END (34)
   - Epic 16 uses full range including TOWN
   - Verify consistent biome ID interpretation

5. **Handler Namespace Verification**
   - Epic 16 handlers: `TransitionToBiome`, `GetCurrentBiome`, etc.
   - Epic 18 handlers: `GenerateDailyRun`, `GetDailyDifficulty`, etc.
   - No overlapping handler names
   - Clear handler ownership
