### Architecture Decision: Extend Existing seasonal-event-engine.lua
**Rationale for Process Reuse:**
- Event species data (`eventEncounters` array) is already embedded in `seasonal-event-engine.lua` from Story 20.1
- Event species availability is determined by active seasonal events and their eventEncounters lists
- Event species logic is lightweight: spawn probability, shiny reroll, form selection, evolution blocking
- Extending existing process avoids cross-process communication overhead and maintains atomicity
- Current process size: ~30KB leaves 470KB headroom for event species handlers

**Implementation Strategy:**
- Add event species handlers to existing `processes/seasonal-event-engine.lua`
- Leverage existing event activation logic (isActive, activeEvent methods)
- Reuse embedded event data with eventEncounters arrays
- Add new handlers: GetEventSpecies, GenerateEventSpecies, TrackEventSpeciesEncounter
- Maintain backward compatibility with existing seasonal event handlers

**Handler: GenerateEventSpecies** [Source: src/data/mystery-encounters/utils/encounter-phase-utils.ts:1008-1049]
- **Trigger Tag**: `Action = "GenerateEventSpecies"`
- **Required Parameters**: `msg.Level` (Pokemon level), `msg.Seed` (RNG seed), `msg.Timestamp` (event timestamp)
- **Optional Parameters**: `msg.IsBoss` (boolean), `msg.RerollHidden` (boolean)
- **Response**: Generated event species with stats or regular species if no event active or RNG selects non-event
- **Spawn Algorithm** [Source: encounter-phase-utils.ts:1014-1033]:
  ```lua
  -- Step 1: Check if any events are active at timestamp
  local activeEvents = getActiveEventsAtTimestamp(msg.Timestamp)
  if #activeEvents == 0 then
    return generateRegularSpecies(msg.Level, msg.Seed, msg.IsBoss)
  end

  -- Step 2: Get all event species from active events
  local eventEncounters = getAllEventEncounters(activeEvents)
  if #eventEncounters == 0 then
    return generateRegularSpecies(msg.Level, msg.Seed, msg.IsBoss)
  end

  -- Step 3: 50% probability for event species selection
  local useEventSpecies = seededRandom(msg.Seed, 0, 1) == 1
  if not useEventSpecies then
    return generateRegularSpecies(msg.Level, msg.Seed, msg.IsBoss)
  end

  -- Step 4: Select random event encounter
  local eventEncounter = seededRandomItem(eventEncounters, msg.Seed + 1)

  -- Step 5: Get species for level (respecting blockEvolution)
  local speciesId = getWildSpeciesForLevel(
    eventEncounter.species,
    msg.Level,
    not eventEncounter.blockEvolution, -- can evolve?
    msg.IsBoss or false
  )

  -- Step 6: Generate Pokemon stats
  local pokemon = generatePokemonStats(speciesId, msg.Level, msg.IsBoss or false)

  -- Step 7: Apply form index if specified
  if eventEncounter.formIndex then
    pokemon.formIndex = eventEncounter.formIndex
  end

  -- Step 8: Apply extra shiny reroll for event species
  pokemon.shinyRerolled = true
  local shinyResult = rerollShiny(pokemon, msg.Seed + 2)

  -- Step 9: Apply optional hidden ability reroll
  if msg.RerollHidden == "true" then
    pokemon.hiddenAbilityRerolled = true
    rerollHiddenAbility(pokemon, msg.Seed + 3)
  end

  return pokemon
  ```

```lua
-- Extend existing seasonal-event-engine.lua from Story 20.1
-- Monolithic design with embedded event data already present

-- New helper functions for event species
local function getAllEventEncounters(activeEvents) ... end
local function generateEventSpecies(level, seed, timestamp, isBoss, rerollHidden) ... end
local function rerollShiny(pokemon, seed) ... end
local function rerollHiddenAbility(pokemon, seed) ... end

-- New handler registration (individual handlers for each action)
Handlers.add("get-event-species",
  Handlers.utils.hasMatchingTag("Action", "GetEventSpecies"),
  function(msg)
    local timestamp = tonumber(msg.Timestamp)
    if not timestamp then
      ao.send({Target = msg.From, Action = "Error", Error = "Timestamp required"})
      return
    end

    local activeEvents = getActiveEventsAtTimestamp(timestamp)
    local eventSpecies = getAllEventEncounters(activeEvents)

    ao.send({
      Target = msg.From,
      Action = "SaveState",
      Data = json.encode({
        eventSpecies = eventSpecies,
        activeEvents = getEventNames(activeEvents),
        spawnProbability = 0.5
      }),
      Success = "true"
    })
  end
)

Handlers.add("generate-event-species",
  Handlers.utils.hasMatchingTag("Action", "GenerateEventSpecies"),
  function(msg)
    local level = tonumber(msg.Level)
    local seed = tonumber(msg.Seed)
    local timestamp = tonumber(msg.Timestamp)

    if not level or not seed or not timestamp then
      ao.send({
        Target = msg.From,
        Action = "Error",
        Error = "Level, Seed, and Timestamp required"
      })
      return
    end

    local isBoss = msg.IsBoss == "true"
    local rerollHidden = msg.RerollHidden == "true"

    local pokemon = generateEventSpecies(level, seed, timestamp, isBoss, rerollHidden)

    ao.send({
      Target = msg.From,
      Action = "SaveState",
      Data = json.encode({speciesGenerated = pokemon}),
      Success = "true"
    })
  end
)
```

**Event Species Spawn Algorithm** [Source: encounter-phase-utils.ts:1014-1033]
```lua
-- Deterministic event species spawn with 50% probability
-- Input: level, seed, timestamp, isBoss (optional), rerollHidden (optional)
-- Output: Pokemon object (event species or regular species)
local function generateEventSpeciesOrRegular(level, seed, timestamp, isBoss, rerollHidden)
  -- Step 1: Check active events
  local activeEvents = getActiveEventsAtTimestamp(timestamp)
  if #activeEvents == 0 then
    return generateRegularSpecies(level, seed, isBoss)
  end

  -- Step 2: Get event encounters
  local eventEncounters = getAllEventEncounters(activeEvents)
  if #eventEncounters == 0 then
    return generateRegularSpecies(level, seed, isBoss)
  end

  -- Step 3: Deterministic 50% probability roll
  local rand = seededRandom(seed, 0, 1)
  if rand == 0 then
    return generateRegularSpecies(level, seed, isBoss)
  end

  -- Step 4: Select random event encounter
  local eventIndex = seededRandom(seed + 1, 1, #eventEncounters)
  local eventEncounter = eventEncounters[eventIndex]

  -- Step 5: Get species for level
  local speciesId = getWildSpeciesForLevel(
    eventEncounter.species,
    level,
    not eventEncounter.blockEvolution,
    isBoss or false
  )

  -- Step 6: Generate Pokemon
  local pokemon = generatePokemonStats(speciesId, level, isBoss or false)
  pokemon.formIndex = eventEncounter.formIndex
  pokemon.blockEvolution = eventEncounter.blockEvolution or false
  pokemon.isEventEncounter = true

  -- Step 7: Apply extra shiny reroll (seed + 2)
  pokemon.shinyRerolled = true
  applyShinyReroll(pokemon, seed + 2)

  -- Step 8: Apply optional hidden ability reroll (seed + 3)
  if rerollHidden then
    pokemon.hiddenAbilityRerolled = true
    applyHiddenAbilityReroll(pokemon, seed + 3)
  end

  return pokemon
end
```
