### Component Specifications

#### AI Move Evaluator Component
[Source: src/field/pokemon.ts#L6479-6710]

**Purpose**: Core AI decision-making component that evaluates all available moves and selects optimal move based on AI type

**VERIFIED Algorithm Breakdown** (Line-by-Line from TypeScript):

1. **Move Queue Processing** (Lines 6482-6495)
   - Check `moveQueue` for queued moves
   - For each queued move: check if virtual (`isVirtual(useMode)`) OR usable
   - If usable: splice queue up to that move and return it
   - If no usable queued move found: clear entire queue (`moveQueue = []`)

2. **Usability Filtering** (Lines 6497-6499)
   - Filter moveset: `movePool = moveset.filter(m => m.isUsable(this))`
   - Returns moves with: PP > 0, not disabled, no restrictions

3. **Single Move Shortcut** (Lines 6501-6508)
   - If `movePool.length === 1`: return that move immediately
   - Skip all scoring and AI logic for efficiency

4. **Encore Forced Move** (Lines 6509-6521)
   - Check for `EncoreTag` on Pokemon
   - If Encore: find move matching `encoreTag.moveId`
   - If found in move pool: return that move (forced)

5. **KO Move Detection** (Lines 6535-6576)
   - Filter moves where: `move.category !== STATUS` AND `moveTarget !== ATTACKER`
   - For each move against each opponent:
     - Check `move.applyConditions()` OR special moves (Sucker Punch, Upper Hand, Thunderclap)
     - Calculate damage with: `getAttackDamage({isCritical: critOnly || ALWAYS_CRIT tag})`
     - If `damage >= opponent.hp`: add to KO moves
   - If `koMoves.length > 0`: replace `movePool` with `koMoves`

6. **Move Benefit Scoring** (Lines 6583-6656)
   - For each move in pool:
     - Get targets from `getNextTargets(moveId)`
     - For each target:
       - Calculate: `targetScore = getUserBenefit(move) + getTargetBenefit(move) * allyFactor`
       - Ally factor: `(targetIndex < ENEMY) === this.isPlayer() ? 1 : -1` (Line 6605)
       - Handle NaN scores → 0 (Line 6606-6609)
       - **Unimplemented/Failing moves**: score = -20 (Lines 6614-6618)
       - **Attack moves** (Lines 6619-6648):
         - Get `effectiveness` from `getMoveEffectiveness()`
         - If opponent: `score *= effectiveness`; if STAB: `score *= 1.5` (Lines 6633-6637)
         - If ally: `score /= effectiveness`; if STAB: `score /= 1.5` (Lines 6638-6642)
         - If score === 0: assume unimplemented, score = -20 (Lines 6644-6647)
     - Move score = `Math.max(...targetScores)` (Line 6652)

7. **Move Pool Sorting** (Lines 6660-6666)
   - Sort moves descending by score: `(a, b) => scoreA < scoreB ? 1 : scoreA > scoreB ? -1 : 0`

8. **AI Type Selection** (Lines 6667-6688)
   - **RANDOM** (Lines 6524-6526):
     - `r = randBattleSeedInt(movePool.length)`
   - **SMART_RANDOM** (Lines 6668-6672):
     - `while (r < length - 1 && randBattleSeedInt(8) >= 5) { r++ }`
     - **VERIFIED**: 5/8 chance stay (0-4), 3/8 chance advance (5-7)
   - **SMART** (Lines 6673-6687):
     - **VERIFIED Algorithm**:
       ```lua
       while r < length - 1
           AND (scores[r+1] / scores[r]) >= 0  -- Skip if negative ratio
           AND randBattleSeedInt(100) < round((scores[r+1] / scores[r]) * 50)
       do
           r = r + 1
       end
       ```
     - Advance probability: `(nextScore / currentScore) * 50`
     - Example: 80/100 score ratio = 40% advance chance

9. **Struggle Fallback** (Lines 6704-6709)
   - If `movePool.length === 0`: return `{move: STRUGGLE, targets: getNextTargets(STRUGGLE), useMode: IGNORE_PP}`

**Decision Flow Summary**:
```
Move Queue → Usability Filter → Single Move? → Encore? → KO Detection →
Benefit Scoring → Sort by Score → AI Type Selection → Return / Struggle
```

  local function selectByAiType(sortedMoves, moveScores, aiType, battleSeed)
      local r = 0  -- Index in sorted move pool

      if aiType == AiType.RANDOM then
          -- Pure random selection
          r = seededRandom(battleSeed, #sortedMoves)
      elseif aiType == AiType.SMART_RANDOM then
          -- 5/8 chance best move, 3/8 advance to next
          while r < #sortedMoves - 1 and seededRandom(battleSeed, 8) >= 5 do
              r = r + 1
          end
      elseif aiType == AiType.SMART then
          -- Advance probability based on score ratios
          while r < #sortedMoves - 1 do
              local currentScore = moveScores[sortedMoves[r]]
              local nextScore = moveScores[sortedMoves[r + 1]]

              -- Skip if next score is negative
              if nextScore / currentScore < 0 then
                  break
              end

              -- Calculate advance probability: (nextScore / currentScore) * 50
              local advanceProbability = math.round((nextScore / currentScore) * 50)

              if seededRandom(battleSeed, 100) < advanceProbability then
                  r = r + 1
              else
                  break
              end
          end
      end

      return r
  end
