**Species Weighting Formula** [Source: src/data/egg.ts:493-496]
```lua
-- Weighting formula for species selection within tier
-- Lower cost species within tier get higher weight (more common)
-- Formula: weight = floor((((maxCost - clampedCost) / (maxCost - minCost + 1)) * 1.5 + 1) * 100)
-- Result: 1 cost = 2x weight, 2 cost = 1.5x weight, higher costs = 1x weight
-- Regional variants (Alolan, Galarian, etc.) get 0.5x weight

function calculateSpeciesWeight(speciesCost, minTierCost, maxTierCost)
  local clampedCost = math.max(minTierCost, math.min(speciesCost, maxTierCost))
  local weight = math.floor((((maxTierCost - clampedCost) / (maxTierCost - minTierCost + 1)) * 1.5 + 1) * 100)
  return weight
end
```

### API Specifications

**Handler: RollEggTier** [Source: Architecture requirements for AO message patterns]
- **Trigger Tag**: `Action = "RollEggTier"`
- **Required Parameters**: `msg.SourceType` (gacha type: "GACHA_LEGENDARY"|"GACHA_SHINY"|"GACHA_MOVE"|"SAME_SPECIES_EGG")
- **Optional Parameters**: `msg.EggPity` (JSON with current pity counters)
- **Response**: Rolled tier with threshold-based determination
- **Validation**: Source type validity, pity counter format
- **Example**:
  ```lua
  -- Request
  {
    Action = "RollEggTier",
    SourceType = "GACHA_LEGENDARY",
    EggPity = json.encode({
      [EggTier.RARE] = 0,
      [EggTier.EPIC] = 0,
      [EggTier.LEGENDARY] = 0
    })
  }

  -- Response
  {
    Action = "SaveState",
    Success = "true",
    Data = json.encode({
      tier = EggTier.LEGENDARY,
      tierName = "LEGENDARY",
      hatchWaves = 100,
      rollValue = 0,  -- Random value (0-255) that determined tier
      thresholdUsed = {
        commonThreshold = 53,  -- +1 offset for legendary gacha
        rareThreshold = 9,
        epicThreshold = 2
      },
      pityForced = false
    })
  }
  ```
