### API Specifications

**Handler: GetModifierInfo** [Source: Architecture requirements for AO message patterns]
- **Trigger Tag**: `Action = "GetModifierInfo"`
- **Required Parameters**: `msg.ModifierId` (modifier type ID)
- **Response**: Complete modifier type configuration
- **Error Conditions**: Invalid modifier ID
- **Example**:
  ```lua
  -- Request
  {Action = "GetModifierInfo", ModifierId = "SPECIES_STAT_BOOSTER"}

  -- Response
  {
    Action = "SaveState",
    Data = json.encode({
      modifier = {
        id = "SPECIES_STAT_BOOSTER",
        tier = "ULTRA",
        localeKey = "modifierType:SPECIES_STAT_BOOSTER",
        group = "statBooster"
      }
    }),
    Success = "true"
  }
  ```

**Handler: GenerateModifierOptions** [Source: src/modifier/init-modifier-pools.ts]
- **Trigger Tag**: `Action = "GenerateModifierOptions"`
- **Required Parameters**: `msg.PoolType` (player, wild, trainer, enemy, dailyStarter), `msg.Wave` (number), `msg.Seed` (RNG seed)
- **Response**: Array of weighted modifier options for selection
- **Example**:
  ```lua
  {
    Action = "SaveState",
    Data = json.encode({
      options = {
        {modifierId = "POTION", weight = 50, tier = "COMMON"},
        {modifierId = "SPECIES_STAT_BOOSTER", weight = 24, tier = "ULTRA"},
        {modifierId = "MEGA_BRACELET", weight = 2, tier = "ROGUE"}
      }
    })
  }
  ```

**Handler: ApplyModifier** [Source: src/modifier/modifier.ts:apply()]
- **Trigger Tag**: `Action = "ApplyModifier"`
- **Required Parameters**: `msg.ModifierId`, `msg.GameState` (JSON), `msg.Args` (modifier-specific arguments)
- **Response**: Updated game state with modifier applied
- **Effect Calculation Formulas** [Source: src/modifier/modifier.ts effect implementations]:
  - **Stat Boost**: `boostedStat = math.floor(baseStat * (1 + boostPercent * stackCount))`
    - Example: ATK 100 with +10% booster (2 stacks) = floor(100 * 1.2) = 120
  - **Healing**: `healAmount = math.floor(maxHP * healPercent * stackCount)`
    - Example: POTION on 100 HP Pokemon = floor(100 * 0.2 * 1) = 20 HP
  - **Probability Multiplier**: `newProb = baseProb * (multiplier ^ stackCount)`
    - Example: Shiny rate 1/4096 with 2x charm (3 stacks) = 1/4096 * 8 = 1/512
  - **Type Damage Boost**: `boostedDamage = math.floor(baseDamage * (1 + 0.2 * stackCount))`
    - Example: 50 damage with type booster (1 stack) = floor(50 * 1.2) = 60
  - **Experience Share**: `sharedExp = math.floor(totalExp / partySize)`
    - Example: 1000 exp with 6 party members = floor(1000 / 6) = 166 per Pokemon
- **Example**:
  ```lua
  {
    Action = "SaveState",
    Data = json.encode({
      gameState = {...}, -- Updated game state
      modifier = {id = "POTION", applied = true, stackCount = 1}
    })
  }
  ```

**Handler: ValidateModifier** [Source: src/modifier/modifier.ts:shouldApply()]
- **Trigger Tag**: `Action = "ValidateModifier"`
- **Required Parameters**: `msg.ModifierId`, `msg.Context` (application context)
- **Response**: Boolean validation result with constraint details
- **Example**:
  ```lua
  {
    Action = "SaveState",
    Data = json.encode({
      valid = true,
      constraints = {maxStack = 3, currentStack = 1, canApply = true}
    })
  }
  ```

**Handler: SerializeModifiers** [Source: src/modifier/modifier.ts serialization]
- **Trigger Tag**: `Action = "SerializeModifiers"`
- **Required Parameters**: `msg.GameState` (JSON with modifiers)
- **Response**: Serialized modifier state for persistence
- **Example**:

        },

```lua
-- Monolithic design with embedded data
local modifierTypes = {...} -- All modifier type data embedded
local modifierPools = {...} -- All pool configurations embedded

local function calculateModifierWeight(modifier, context) ... end

Handlers.add("get-modifier-info",
  Handlers.utils.hasMatchingTag("Action", "GetModifierInfo"),
  function(msg)
    local modifierId = msg.ModifierId
    if not modifierId then
      ao.send({Target = msg.From, Action = "Error", Error = "ModifierId required"})
      return
    end

    local modifierType = getModifierType(modifierId)
    if not modifierType then
      ao.send({Target = msg.From, Action = "Error", Error = "Modifier not found"})
      return
    end

    ao.send({
      Target = msg.From,
      Action = "SaveState",
      Data = json.encode({modifier = modifierType}),
      Success = "true"
    })
  end
)
```

**AO Compliance Requirements** [Source: docs/architecture/tech-stack.md#process-implementation-requirements]
- Monolithic Design: All modifier data embedded in single file (or split if size constraint exceeded)
- Handler Pattern: Use `Handlers.add()` with individual handlers per action (no multi-action handlers)
- Error Handling: Direct validation and error responses, avoid unnecessary pcall usage
- **CRITICAL**: Never use pcall for simple data access (table lookups, parameter validation)
- **CRITICAL**: Use pcall ONLY for operations that genuinely might fail (external JSON parsing from untrusted sources)
- Available Globals: ao.send(), ao.id, Handlers, json, standard Lua (string, table, math)

- `require()` - No external module loading (except require("json") which is permitted)
- `os.time()` - Use `msg.Timestamp` instead
- `io` - No file system access
- `debug` - Debug library unavailable
- Network operations - Only through ao.send()
- Math.random() - Use AO crypto module for deterministic RNG with seeded generation

**Coding Standards** [Source: docs/architecture/coding-standards.md]

**Weighted Selection Algorithm** [Source: Standard weighted random selection pattern]
```lua
-- Deterministic weighted random selection
-- Input: options table with {modifierId, weight, tier}, seed value
-- Output: selected option
local function selectWeightedModifier(options, seed)
  -- Calculate total weight
  local totalWeight = 0
  for _, option in ipairs(options) do
    totalWeight = totalWeight + option.weight
  end

  -- Generate deterministic random value [0, totalWeight)
  local rand = seededRandom(seed, 0, totalWeight - 1)

  -- Select option based on cumulative weights
  local cumulative = 0
  for _, option in ipairs(options) do
    cumulative = cumulative + option.weight
    if rand < cumulative then
      return option
    end
  end

  -- Fallback: return last option (should never reach here)
  return options[#options]
end

-- Example usage for GenerateModifierOptions handler
-- Seed 12345 with options [POTION:50, STAT_BOOSTER:24, MEGA_BRACELET:2]
-- Total weight = 76
-- rand = seededRandom(12345, 0, 75) = 38 (example)
-- Cumulative: 0->50 (POTION), 50->74 (STAT_BOOSTER), 74->76 (MEGA_BRACELET)
-- Result: STAT_BOOSTER selected (38 falls in 50-74 range)
```
