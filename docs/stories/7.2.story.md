### TypeScript Reference Implementation
**Side Effect Implementation Points** [Source: typescript-reference/src/data/arena-tag.ts]:

**ReflectTag Class** (lines 310-329):
- Extends WeakenMoveScreenTag with MoveCategory.PHYSICAL protection
- Damage reduction: 1/2 in single battles, 2/3 in double battles
- Side-specific application (ArenaTagSide.PLAYER or ArenaTagSide.ENEMY)
- Can be bypassed by Infiltrator ability
- Default duration: 5 turns, extended by Light Clay item

**LightScreenTag Class** (lines 335-353):
- Extends WeakenMoveScreenTag with MoveCategory.SPECIAL protection
- Damage reduction: 1/2 in single battles, 2/3 in double battles
- Side-specific application with identical mechanics to Reflect
- Bypassed by Infiltrator ability, extended by Light Clay

**WeakenMoveScreenTag Base Class** (lines 270-300):
- Abstract base for screen effects (Reflect, Light Screen, Aurora Veil)
- `apply()` method: Checks move category, applies Infiltrator bypass, calculates damage multiplier
- Double battle detection: `globalScene.currentBattle.double ? 2/3 : 1/2`
- Returns boolean indicating if effect was applied

**SafeguardTag Class** (lines 1336-1356):
- Extends ArenaTag with side-specific status condition protection
- Prevents status conditions (sleep, paralysis, poison, burn, freeze, confusion)
- Default duration: 5 turns
- Does not protect against already existing status conditions
- Can be removed by moves like Defog

**MistTag Class** (lines 209-230):
- Extends SerializableArenaTag with stat reduction protection
- Prevents stat stage reductions from opponent's moves
- Side-specific application protecting team's Pokemon
- Default duration: 5 turns
- Does not prevent stat increases or self-inflicted stat changes

**Arena Tag Base Mechanics**:
- All side effects are side-specific (ArenaTagSide.PLAYER or ArenaTagSide.ENEMY)
- Turn counting decrements at end of each turn
- Effects persist until turn count reaches 0 or explicitly removed
- Light Clay item extends screen duration to 8 turns
- Brick Break and Psychic Fangs remove screens, Defog removes all effects

```lua
SideEffectState = {

    protected = "boolean", -- Whether protection was granted (status/stat protection)
    overwritten = "boolean" -- Whether previous effect was replaced
}
```

### API Specifications
**Side Effect Process Message Protocol** [Source: architecture/tech-stack.md#process-communication-protocol]:

**Incoming Message Structure**:
```lua
-- Apply side effect
msg = {
    Action = "ApplySideEffect",
    EffectType = "REFLECT|LIGHT_SCREEN|SAFEGUARD|MIST",
    Side = "PLAYER|ENEMY",
    SourceId = "123", -- Pokemon ID (as string)
    SourceMove = "REFLECT", -- Move that created effect
    IsDoubleBattle = "false", -- Battle format affects damage reduction
    HasLightClay = "false", -- Item extends duration
    BattleId = "battle_123",
    Timestamp = "1234567890"
}

-- Check effect protection
msg = {
    Action = "CheckSideEffectProtection",
    EffectType = "REFLECT|LIGHT_SCREEN|SAFEGUARD|MIST",
    Side = "PLAYER|ENEMY",
    MoveCategory = "PHYSICAL|SPECIAL", -- For screen checks
    AttackerHasInfiltrator = "false", -- Ability bypass check
    StatusType = "POISON", -- For Safeguard status protection
    StatType = "ATTACK", -- For Mist stat protection
    BattleId = "battle_123",
    Timestamp = "1234567890"
}

-- Remove side effects
msg = {
    Action = "RemoveSideEffects",
    RemovalType = "BRICK_BREAK|DEFOG|PSYCHIC_FANGS|TURN_EXPIRY",
    EffectTypes = "REFLECT,LIGHT_SCREEN", -- Specific effects to remove
    Side = "PLAYER|ENEMY|BOTH", -- Which side's effects to remove
    BattleId = "battle_123",
    Timestamp = "1234567890"
}
```

**Outgoing Response Structure**:
```lua
ao.send({
    Target = msg.From,
    Action = "SaveState",
    Data = json.encode({
        sideEffectState = sideEffectStateData,
        applicationResult = {
            applied = true,
            damageReduction = 0.5, -- Damage multiplier for screens
            bypassedReason = "", -- Empty if not bypassed
            protected = true, -- Status/stat protection granted
            overwritten = false -- Whether previous effect replaced
        }
    }),
    Success = "true",
    ProcessId = ao.id,
    Timestamp = tostring(msg.Timestamp or 0)
})
```
