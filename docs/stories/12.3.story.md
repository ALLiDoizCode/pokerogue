### Comprehensive TypeScript Tera Crystal Analysis

#### Core Tera Crystal Components [Source: TypeScript codebase analysis]

**1. Tera Orb (TerastallizeAccessModifier)**
- **Purpose**: Global unlock for Terastallization capability across all Pokemon
- **Acquisition**: Random drops, champion rewards, achievement unlocks
- **Properties**: Max stack 1 (permanent unlock), ULTRA tier rarity
- **Drop Algorithm**: `Math.min(Math.max(Math.floor(waveIndex / 50) * 2, 1), 4)` weight calculation

**2. Tera Shards (TerastallizeModifier)**  
- **Purpose**: Type-specific consumable items for changing Pokemon's Tera type
- **Types**: 18 regular types + Stellar type (1/64 special probability)
- **Properties**: Single-use consumable, ULTRA tier rarity, Pokemon-specific application
- **Generation Logic**: Excludes current party's uniform Tera type if all Pokemon share same type

#### Drop Rate and Generation Systems [Source: src/modifier/init-modifier-pools.ts]

**Wave-Based Progression:**
```lua
-- Tera Orb drop weight calculation
local function calculateTeraOrbWeight(waveIndex)
    return math.min(math.max(math.floor(waveIndex / 50) * 2, 1), 4)
end

-- Progressive unlock system:
-- Waves 1-49: Weight 1 (very rare)
-- Waves 50-99: Weight 2 (rare) 
-- Waves 100-149: Weight 4 (uncommon)
-- Waves 150+: Weight 4 (capped)
```

**Tera Shard Generation Algorithm:**
```lua
local teraShardTypes = {
    -- Regular types: equal probability (17/18 each)
    NORMAL = true, FIRE = true, WATER = true, ELECTRIC = true,
    GRASS = true, ICE = true, FIGHTING = true, POISON = true,
    GROUND = true, FLYING = true, PSYCHIC = true, BUG = true,
    ROCK = true, GHOST = true, DRAGON = true, DARK = true,
    STEEL = true, FAIRY = true,
    
    -- Stellar type: special 1/64 probability
    STELLAR = false  -- Special case handling
}

local function generateTeraShardType(partyTeraTypes, rngSeed)
    -- Exclude uniform party types
    local availableTypes = filterExcludedTypes(teraShardTypes, partyTeraTypes)
    
    -- Stellar special probability (1/64)
    if rng.random(64) == 1 then
        return "STELLAR"
    end
    
    -- Regular type selection
    return rng.choice(availableTypes)
end
```

#### Usage Tracking and Consumption [Source: src/field/arena.ts, src/phases/tera-phase.ts]

**Per-Battle Usage Limitation:**
```lua
-- Battle state tracking
local battleState = {
    playerTerasUsed = 0,  -- Reset each battle/heal
    teraOrbUnlocked = false,  -- Permanent modifier check
    teraShardInventory = {}  -- Per-Pokemon type assignments
}

-- Usage validation
local function canTerastallize(pokemon, battleState)
    return battleState.teraOrbUnlocked and 
           battleState.playerTerasUsed == 0 and
           not pokemon.isTerastallized and
           not isBlocked(pokemon)
end

-- Consumption tracking
local function useTerastallization(pokemon, battleState)
    pokemon.isTerastallized = true
    battleState.playerTerasUsed = battleState.playerTerasUsed + 1
    -- Tera Orb remains available (not consumed)
    -- Tera Shard effect already applied to pokemon.teraType
end
```
